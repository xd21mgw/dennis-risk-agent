# Data Agent 结论阈值 v1

## 0. 使用原则

本文件定义“Data Agent 返回后够不够下结论”。阈值不使用固定数值，不编造内部真实阈值，只定义证据组合原则。

四档结论：

- 明确判断：强证据链闭合，关键反证已排除，可进入强治理或高准策略。
- 高度疑似：中强证据成组，但仍缺少一两个闭环证据，适合灰度、复核、加采。
- 证据不足：只有弱信号或单点异常，不能定性，进入补证和监控。
- 反向排除 / 暂不支持：出现明确反证，或更合理解释成立，暂不支持该风险判断。

## 1. 协议攻击

明确判断：无正常端链路、接口直达、接口序列固化、签名/token/device/ip/ua 异常，且排除埋点缺失、官方工具、破解包绕采集。

高度疑似：服务端请求与端链路冲突，接口序列异常，但包证据或 token 证据未闭合。

证据不足：只有高频访问、只有前端无日志、只有接口调用量上涨。

反向排除 / 暂不支持：官方工具授权调用、官方包同样缺日志、埋点口径变化可解释。

## 2. 群控

明确判断：设备/账号团组、同批启动停止、行为路径高度相似、收益聚集、无合法矩阵授权，链路稳定复现。

高度疑似：设备团组和行为路径异常明显，但收益链或调度证据不足。

证据不足：只有多设备、多账号、高频或地理聚集。

反向排除 / 暂不支持：合法商家/MCN/客服矩阵、活动自然高峰、企业网络、测试流量。

## 3. 破解包

明确判断：风险请求集中于异常包签名/版本/渠道，SDK 或安全模块缺失/替换，dex/so/assets 或 runtime 行为异常，并能解释端侧日志缺失。

高度疑似：SDK 覆盖缺失与版本/渠道强相关，但工件级证据未完整。

证据不足：只有前端日志缺失或个别版本异常。

反向排除 / 暂不支持：官方包同版本同样缺日志，或采集链路故障可解释。

## 4. 真人众包

明确判断：行为真实但目标任务化，任务完成窗口集中，教程话术/任务平台/收益链/提现聚集证据闭合，设备相对离散。

高度疑似：真实用户完成同类任务、后验质量低、奖励聚集，但缺任务平台或话术证据。

证据不足：只有设备离散、目标一致或低留存。

反向排除 / 暂不支持：自然活动传播、达人运营、正常用户兴趣聚集、业务机制导致路径一致。

## 5. 反爬资产泄漏

明确判断：核心资产被低成本批量获取，访问入口、抓取链路、时间差、外部复用或变现证据闭合。

高度疑似：外部同步明显且内部访问异常，但抓取入口或主体未闭合。

证据不足：只有外网跟价、舆情截图或单点外部样本。

反向排除 / 暂不支持：合作方同步、CDN/cache、前端公开信息、人工访问、内部导出更能解释。

## 6. 导流截流

明确判断：信息暴露入口、目标获取路径、搜索/关注/私信触达、站外承接、账号矩阵或收益链闭合。

高度疑似：批量触达和目标获取明显，但站外承接证据不足。

证据不足：只有私信/关注异常、单账号偶发或用户主动作外联。

反向排除 / 暂不支持：正常社交、普通关注、授权客服/达人运营、无站外承接证据。

## 7. 渠道抢量 / 归因劫持

明确判断：CTIT 异常、自然量跷跷板、渠道后验质量异常、设备/IP/UA/点击行为异常、归因链路可复现。

高度疑似：CTIT 和自然量结构异常，但渠道行为或后验质量证据不完整。

证据不足：只有某渠道转化上涨或 CTIT 偏移。

反向排除 / 暂不支持：预算变化、活动排期、归因规则调整、版本发布、媒体策略变化。

## 8. token 泄露

明确判断：token 在新设备/IP/UA/SDK 环境被使用，无登录迁移/验证链路，并伴随敏感动作或批量模板化使用。

高度疑似：token 使用环境异常和敏感动作相关，但缺登录/验证链路证据。

证据不足：只有 IP 漫游、多设备登录或单次 UA 变化。

反向排除 / 暂不支持：正常换机、可信设备确认、企业网络、漫游、SDK 升级。

## 9. 撞库 / ATO

明确判断：批量登录失败/成功模式、密码或验证码攻击链、登录环境突变、接管后敏感动作、受害账号画像闭合。

高度疑似：登录失败/成功异常和环境突变明显，但接管后行为不完整。

证据不足：只有登录失败上升或单点异地登录。

反向排除 / 暂不支持：正常大促登录、版本问题、验证码故障、企业网络集中登录。

## 10. 活动黑产

明确判断：活动任务路径模板化、设备/账号团组、奖励/提现聚集、规则规避、后验质量异常闭合。

高度疑似：奖励聚集和任务窗口异常明显，但组织化或规避证据不足。

证据不足：只有低留存、低付费或奖励领取多。

反向排除 / 暂不支持：活动机制吸引低质用户、真实传播、业务目标本身偏拉新。

## 11. 活动低质

明确判断：参与用户后验留存、付费、复访、业务价值显著低于合理对照，但缺少组织化黑产证据。

高度疑似：质量差异明显，但需要更多时间窗口或对照组确认。

证据不足：样本小、窗口短、对照不合理。

反向排除 / 暂不支持：活动目标是曝光或冷启动，短期钱效不是唯一指标。

## 12. 合法矩阵 / 超范围违规

明确判断：授权主体、账号范围、工具来源、操作人、审计链路清楚；若动作超范围，则能定位具体账号/工具/接口/操作人/收益主体。

高度疑似：存在授权和业务合理性，但范围或审计不完整。

证据不足：只有批量操作，缺授权、工具和审计信息。

反向排除 / 暂不支持：无授权、工具来源不明、规避平台规则、收益主体异常且风险链路闭合，应转黑产/群控/协议/导流判断。

## 13. DAU/DNU 作弊

明确判断：DAU/DNU 异常已排除口径、采集、SLA、实验、活动和版本影响，并叠加设备/账号/行为/收益/渠道作弊证据。

高度疑似：指标异常和部分风险证据相关，但数据口径或业务变更尚未完全排除。

证据不足：只有 DAU/DNU 波动、单个看板异常或数据延迟。

反向排除 / 暂不支持：口径变更、埋点故障、实验流量、活动峰值、版本发布、数据 SLA 问题。
