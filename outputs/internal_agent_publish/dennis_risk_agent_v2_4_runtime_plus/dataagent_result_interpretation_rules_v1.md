# Data Agent 返回结果解释规则 v1

## 0. 总原则

Data Agent 返回的是数据结果，不是风控结论。Dennis 风控 Agent 必须完成二次解释：

1. 结果支持哪个风险假设。
2. 证据强度是强、中、弱还是反证。
3. 是否存在业务合理解释。
4. 是否足够下结论。
5. 下一步是补证、监控、灰度、局部治理还是强处置。

## 1. 前端无日志不等于一定协议

可能解释：

- 协议脱端。
- 破解包绕过 SDK 或安全模块。
- 官方包埋点缺失。
- SDK 采样、网关采样、日志延迟。
- 版本、渠道或口径差异。

强结论条件：无端链路 + 接口直达 + 接口序列固化 + token/device/ip/ua 异常，且排除埋点/版本/破解包反证。

降级：只有服务端请求、前端无日志时，最多为“链路冲突待补证”。

## 2. 设备聚集不等于一定群控

可能解释：

- 群控设备团组。
- 商家、MCN、客服、机构合法运营。
- 企业网络、机房网络、公共 Wi-Fi。
- 活动高峰或自然热点。
- 测试、压测、蓝军或内部运营。

强结论条件：设备团组 + 同批启停 + 行为路径相似 + 收益聚集 + 无合法授权/审计。

降级：只有设备聚集时，最多为“设备聚集异常”。

## 3. 行为真实不等于一定正常用户

可能解释：

- 自然用户。
- 真人众包。
- 活动低质。
- 达人/商家运营任务。
- 教程化传播带来的路径相似。

强结论条件：真实行为 + 目标任务化 + 任务窗口集中 + 收益/提现聚集 + 教程话术或任务平台线索。

降级：设备离散、行为真实但目标一致时，优先进入真人众包或低质嫌疑，不直接判自然用户。

## 4. 低钱效不等于一定黑产

可能解释：

- 活动机制带来的低质用户。
- 渠道质量差。
- 新客培育周期较长。
- 冷启动或地域/品类结构差异。
- 黑产套利。

强结论条件：低钱效 + 奖励/提现聚集 + 设备/账号/路径/收益组织化 + 规避规则证据。

降级：只有低留存、低付费、低 ROI 时，按低质用户和业务钱效治理。

## 5. 接口化调用不等于一定协议攻击

可能解释：

- 官方工具或授权 ISV。
- 商家/达人/MCN 合法矩阵。
- 服务端业务系统批处理。
- 协议攻击或未授权脚本。

强结论条件：接口化调用 + 无授权/超授权 + 无端链路 + 签名/token/参数异常 + 规避平台规则或收益异常。

降级：存在合法运营可能时，先进入合法矩阵判断。

## 6. 授权矩阵不等于一定安全

可能解释：

- 合法运营矩阵。
- 授权内正常批量操作。
- 授权工具被超范围使用。
- 操作人滥用权限。
- 合法主体下的导流、欺诈、支付或结算风险。

强结论条件：有授权但动作、账号、接口、时间、收益主体或触达目的超范围，且形成局部风险链路。

降级：有授权但证据不足时，不做主体级封禁，进入局部审计和敏感动作限权。

## 7. CTIT 异常不等于一定渠道作弊

可能解释：

- 归因劫持或抢量。
- 渠道投放策略变化。
- 归因规则或 SDK 口径变更。
- 活动大促、预算调整。
- 网络环境或安装包分发差异。

强结论条件：CTIT 异常 + 自然量跷跷板 + 后验质量异常 + 设备/IP/UA 或渠道行为异常。

降级：只有 CTIT 分布异常时，最多为“渠道归因异常待复核”。

## 8. 外网跟价不等于一定内部接口被爬

可能解释：

- 内部接口被爬。
- CDN/cache 泄漏。
- 前端公开数据被抓。
- 合作方或商家侧同步。
- 内部导出或人工访问。
- 真实用户观察后外部同步。

强结论条件：外网跟价 + 内部接口异常访问 + 低成本批量获取 + 时间差稳定 + 访问链路闭合。

降级：只有外网跟价，没有内部接口异常时，按资产泄漏多路径排查。

## 9. DAU/DNU 异常不等于一定黑产

可能解释：

- 数据口径变化。
- 埋点/采集/SLA 问题。
- 实验流量。
- 版本发布或活动冲击。
- 渠道结构变化。
- 作弊流量。

强结论条件：DAU/DNU 异常 + 设备/账号/行为/收益/渠道证据组合，且排除口径和数据质量问题。

降级：先做口径校验、数据矫正、SLA 和监控，不直接定黑产。

## 10. 私信/关注异常不等于一定导流黑产

可能解释：

- 正常社交互动。
- 普通关注。
- 客服、商家、达人、MCN 授权触达。
- 用户主动外联。
- 导流截流或骚扰。

强结论条件：目标获取入口 + 批量搜索/关注/私信 + 站外承接证据 + 账号矩阵或收益链。

降级：无站外承接证据或单个账号偶发行为时，最多为导流嫌疑或触达异常。

## 11. 解释输出模板

```text
Data Agent 返回摘要：
支持的风险假设：
可作为强证据：
只能作为中/弱证据：
反证与业务合理解释：
当前最多能下的结论：
仍需补证：
建议治理动作：
不得直接执行的动作：
```
