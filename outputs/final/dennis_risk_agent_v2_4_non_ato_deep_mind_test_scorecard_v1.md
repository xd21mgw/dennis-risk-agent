# Dennis Risk Agent v2.4 Non-ATO Deep Mind Test Scorecard v1

## 1. 结论摘要

本轮 8 个非 ATO 场景问题，整体表现为：

- 已经具备“完全体脑子雏形”。
- 反爬 / 协议 / 群控 / 破解包 / 真人众包 / 活动反作弊 / 导流截流 / 流量反作弊都能做到：
  - 先识别场景；
  - 再讲风险本质；
  - 再拆攻击路径；
  - 再给证据优先级、误判边界、治理动作和补证方向。
- 其中 Q6、Q8 的弱点最明显，主要不是判断能力不够，而是缺少更结构化的分层模板。

总体判断：

- **无需立即升级为新完全体**。
- **反爬 / 资产保护最适合作为 v2.5 第二个完全体样板**。
- 协议、群控、破解包、真人众包适合并入反爬大 Skill 包做深度组合。
- 活动反作弊 / 流量反作弊可作为 P1。
- 导流治理暂不作为本轮重点。

## 3. 分领域判断

### 3.1 已经接近 deep skill 的领域

以下领域已经接近 deep skill 的判断深度：

- 反爬 / 资产保护。
- 协议攻击。
- 群控。
- 破解包。

这些领域的共性是：

- 能稳住风险本质。
- 能拆多条攻击路径。
- 能讲清强 / 中 / 弱证据和反证边界。
- 能给低成本取证方向和治理分层。

### 3.2 runtime summary 已可用，但还没到 deep skill 的领域

- 真人众包。
- 活动反作弊。
- 流量反作弊。

这些场景已经可用，但与 deep skill 还有一点距离，主要差在：

- 更细的样板库。
- 更细的分层模板。
- 更细的治理动作与结算口径联动。

### 3.3 需要补充样板的领域

- 真人众包：需要更多“真人任务化”与“自然用户”分界样板。
- 流量反作弊：需要更多“渠道套利 / 低质 / 自然波动”样板。
- 活动反作弊：需要更多“裂变正常增长 vs 套利”样板。
- 导流截流：本轮没作为重点，需要后续单独补样板。

## 4. 是否建议立即升级完全体

结论：**不建议立即升级为新的完全体**。

理由：

- 当前 8 题已经证明“完全体脑子雏形”成立。
- 但还没有必要把所有非 ATO 场景都拉成完整 deep skill。
- 更合理的路径是：
  - 反爬 / 资产保护先升为第二个完全体样板。
  - 协议、群控、破解包、真人众包并入反爬大 Skill 包。
  - 活动反作弊 / 流量反作弊作为 P1。
  - 导流治理后续再看。

## 5. 特别标注

### 5.1 反爬 / 资产保护是否适合作为 v2.5 第二个完全体

**适合。**

原因：

- 风险本质明确。
- 攻击路径清晰。
- 证据优先级完整。
- 与协议、群控、破解包、真人众包有稳定边界。

### 5.2 协议、群控、破解包、真人众包是否适合并入反爬大 Skill 包

**适合。**

原因：

- 这些手法在反爬场景里高频混合出现。
- 并入大包有助于统一边界和治理语言。
- 但仍应保留独立 runtime summary 或独立子段，避免边界丢失。

### 5.3 活动反作弊 / 流量反作弊是否作为 P1

**适合，且优先级高于导流治理。**

原因：

- 两者都已经具备较完整的短问支持。
- 但还缺更细的样板和结算 / 后验质量联动模板。

### 5.4 导流治理是否暂不作为本轮重点

**是。**

原因：

- 当前已有可用 summary，但离深度样板还有距离。
- 先把反爬 / 活动 / 流量这几条跑稳更合适。

## 6. Q6 / Q8 最小补强建议

### 6.1 Q6 最小补强：三分法模板

建议补成以下三分法：

1. **自然低质用户**
   - 行为真实。
   - 目标不组织化。
   - 留存 / 转化差但没有任务化和聚集证据。

2. **渠道低质流量**
   - 来源偏差明显。
   - 后验质量差。
   - 可能存在倒量、套利或投放口径问题。

3. **真人众包**
   - 行为真实。
   - 但目标任务化、组织化。
   - 常伴随派单、佣金、结算、任务群。

### 6.2 Q8 最小补强：渠道结算口径模板

建议补成结构化模板：

- 渠道结算口径。
- 风控指标口径。
- 留存 / 转化 / 付费联动。
- 异常激活节奏。
- 审计与止损动作。
