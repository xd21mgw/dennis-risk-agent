# Case MIX-001 回归评审

## 原始问题

直播间公开展示/口播用户信息后，黑产搜索用户 ID 定向添加并私信导流，怎么还原证据链和治理？

## Skill 路由

- 主控 Skill：traffic_diversion_interception_skill
- 辅助 Skill：anti_crawler_expert_skill、account_security_expert_skill、evidence_decomposition_skill、risk_chain_reconstruction_skill、risk_governance_design_skill

## 回答

一句话判断：这是“目标获取 → 搜索定位 → 关系建立 → 私信导流 → 站外变现”的链路型导流风险，直播间公开信息是目标泄露入口，不能只按私信违规或单点爬取处理。

领域归类：导流截流，兼具反爬中的用户信息资产保护。

风险类型：导流截流 / 目标信息滥用 / 可能混合真人众包、群控账号矩阵和小号。

黑产本质：
- 作恶方：导流团伙、私域成交团队、诈骗/灰产承接方、账号矩阵运营者。
- 上游资源：直播间公开展示的用户 ID、口播信息、评论区线索、搜索能力、私信账号池。
- 中游执行：监听直播或录屏识别目标，搜索用户 ID，定向关注/添加，私信发送站外联系方式或诱导话术。
- 下游变现：站外成交、诈骗引流、私域流量沉淀、账号交易、竞品截流。
- 平台被利用环节：直播展示、搜索可达性、关注/私信触达、站外联系方式治理。
- 最适合治理节点：展示脱敏和搜索限制是源头，私信风控和账号矩阵治理是闭环。

关键证据：
- 强证据：被添加用户与直播展示/口播时间强相关；黑产搜索时间紧跟直播曝光；搜索关键词等于用户 ID 或口播信息；关注/私信动作紧随搜索；多个黑产账号围绕同一批直播目标重复触达；私信含站外联系方式或固定导流话术。
- 中证据：添加账号低质或矩阵化；直播间后私信投诉上升；触达对象集中于被展示用户；同设备/IP 多账号搜索相同目标。
- 弱证据：私信量上升、搜索量上升、低质账号增多、用户投诉“被骚扰”。这些不能单独证明直播泄露链路。
- 反证 / 误判：用户主动公开 ID；正常粉丝关注；主播活动要求添加；同名误搜；推荐/同城曝光带来的自然关注；埋点缺搜索来源。

补证动作：
- 建时间线：直播展示/口播时间、目标 ID、搜索时间、关注时间、私信时间、站外承接时间。
- 前后端 join：直播曝光、评论/口播记录、搜索词、主页访问、关注、私信、举报。
- 查矩阵：发送方账号-设备-IP-话术-站外联系方式-目标用户团组。
- 查内容证据：私信话术、外部联系方式、落地页、群链接、诈骗或成交证据。
- 查业务边界：主播活动规则、用户授权展示、正常粉丝互动、运营白名单。

治理方案：
- 源头治理：直播间用户 ID 脱敏、敏感信息口播提醒、主播侧违规提示和教育、展示权限控制。
- 搜索治理：对刚被直播曝光的敏感 ID 做搜索冷却、搜索频控、异常搜索降权，限制低可信账号连续搜索。
- 私信治理：新关注后私信风控、站外联系方式识别、话术相似度、账号矩阵封禁/限权。
- 用户保护：被曝光用户提醒、私信过滤、举报快捷入口、高风险触达拦截。
- 法务/运营：沉淀证据链，推动主播规范和站外承接打击。

灰度策略：
- 先在高投诉直播间、高风险主播、高敏用户信息类型上灰度。
- 对搜索侧先做频控和冷却，对私信侧按置信度分层拦截。
- 高置信账号矩阵强处置，中置信限制触达，低置信加采。
- 对正常粉丝、主播活动、客服运营账号保留授权和审计机制。

评估指标：
- 被展示用户私信骚扰率、直播后搜索转私信转化率、导流账号召回/准确率、站外联系方式拦截量、用户投诉、主播侧影响、误伤率、黑产迁移到评论/主页/昵称导流的比例。

可沉淀资产：
- 导流链路证据模板、直播信息展示风险规范、搜索-私信联动策略、站外联系方式库、账号矩阵图谱、用户保护看板。
