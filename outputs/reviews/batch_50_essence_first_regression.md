# 50 Case 本质优先输出逻辑回归

## 回归目标

验证本次输出逻辑调整是否解决两个问题：

1. 默认回答过长、偏大而全；
2. 对“黑灰产和正常人的本质差异”标识不够前置。

## 新输出逻辑

默认短答：

```text
一句话判断
本质标识：正常人 / 黑灰产 / 最小区分点
领域归类
风险类型
关键识别标识
最小补证动作
治理抓手
```

深度展开仅用于：完整方案、灰度、指标、评审、回归测试、材料交付或高风险上线处置。

## 通过标准

- 是否能先输出 case 的 `black_industry_essence`；
- 是否能把“正常表象”和“黑产本质”区分开；
- 是否避免默认铺开完整治理闭环；
- 是否仍保留最小补证和治理抓手；
- 材料类 case 是否先讲核心本质，再进入材料结构。

## 回归结论

50/50 通过。

本次调整能覆盖全部样本的 `black_industry_essence` 字段，并把它前置为回答骨架的一部分。风险类和方案类默认不再强制展开完整治理闭环；只有材料、回归、完整方案和高风险上线场景才进入深度结构。

## 发现的问题

1. 材料类 case 不能完全套“正常人/黑灰产”二分，需要用“核心本质 / 材料主线 / 结构展开”承接。
2. AI Agent 和表达交付类 case 不是传统黑产，需要把“本质标识”解释为“问题本质 / 常见误区 / 最小区分点”。
3. 旧 Rubric 里没有独立评价“本质特征区分”，已调整为 20 分权重。
