# Sheet2 多样性与适用边界评估

## 1. 基本结论

Sheet2 是近期高置信 ATO 正例样本池，适合做地推扫码、钓鱼 / web 登录、短信验证码泄露的正例回归和 Data Agent 匹量种子。

但 Sheet2 不适合单独作为完整账号安全回归集。它缺少非盗号反例、不确定样本、长期历史样本、策略误伤样本和足够多的 token / 租借账号边界样本，存在明显过拟合近期欺诈盗号正例的风险。

- 缺少负例、不确定样本、误伤样本。
- 不能单独验证“反例不强判”能力。

- 登录信息泄露、token 泄露样本偏少。

- 该字段适合做 query hint，不适合直接做 evidence。

## 4. 多样性风险

Sheet2 缺少或不足：

| 缺口 | 风险 |
|---|---|
| 非盗号反例 | 无法验证不强判能力 |
| 不确定样本 | 无法验证 insufficient_support 边界 |
| token 泄露充分样本 | 只有少量 token 标签，缺完整 token/session 链路 |
| 账号交易 / 租借账号样本 | 只有 1 条租借账号，无法形成稳定判断规则 |
| 历史 case | 仅少量历史盗号，无法评估长周期 |
| 策略误伤 / 申诉误判样本 | Sheet2 全为正例，不覆盖误伤 |
| 其他下游作恶类型 | 主要集中色情 / 招嫖 |
| 空值 / 标签冲突样本 | 有少量空值，但不足以做质量回归 |

## 5. 过拟合风险判断

风险等级：高。

Sheet2 容易让模型或规则过拟合为：

```text
用户说扫码 / 链接 / 验证码
→ 色情 / 招嫖内容
→ 盗号成立
```

这会导致：
- 对非盗号封禁客诉过判。
- 对用户主动分享、账号租借、历史处罚误判。
- 对只有发布行为但无登录态接管链路的样本强判。
- 对 token/session、密码泄露、找回漏洞等非欺诈路径覆盖不足。

必须用 Sheet1 的反例、不确定、历史 case 和空标签样本做配平。

## 6. Sheet2 适用场景

Sheet2 适合用于：

- 近期高置信盗号正例样本池。
- 地推扫码欺诈回归。
- 钓鱼 / web 短信验证码登录回归。
- 短信验证码泄露小样本回归。
- Data Agent 批量匹量种子样本。
- 验证“用户自述 → Data Agent 取证 → evidence → Dennis 解释”的正例流程。
- 训练 query_intent 模板中的最小证据链。

## 7. Sheet2 不适合单独用于

Sheet2 不适合单独用于：

- 完整账号安全回归集。
- 多样性充分的盗号评估集。
- 误伤 / 非盗号评估。
- 长周期稳定性评估。
- token/session 专项覆盖评估。
- 账号租借 / 主动分享 / 合法授权边界评估。
- 策略误伤或申诉误判分析。

## 8. 配平建议

建议构建 ATO 回归集时按以下比例：

| 类型 | 建议比例 | 来源 |
|---|---:|---|
| Sheet2 地推 / 钓鱼 / 短信正例 | 40% | Sheet2 |
| Sheet1 非盗号 / 误报 / 导流 / 反诈 | 20% | Sheet1 |
| Sheet1 不确定 / 证据不足 | 15% | Sheet1 |
| Sheet1 历史 case / 标签缺失 | 10% | Sheet1 |
| token/session / 平台漏洞线索 | 10% | Sheet1 + Sheet2 |
| 租借账号 / 主动分享边界 | 5% | Sheet1 |

## 9. 对 Data Agent 批量验证的建议

第一轮不要只跑 Sheet2 正例。

建议选择：
- Sheet2 地推扫码 5 条。
- Sheet2 钓鱼 / web 短信验证码 5 条。
- Sheet2 token / 短信小类 3 条。
- Sheet1 非盗号反例 5 条。
- Sheet1 不确定样本 3 条。
- Sheet1 历史 case / 标签缺失样本 3 条。

验证目标：
- 正例是否能闭合“登录/授权/token → 发布/敏感动作”链路。
- 反例是否能保留正常解释。
- 未回扫 / 已回捞是否能被数据验证。
- 标签缺失样本是否能通过数据补充，而不是人工猜测。

## 10. 结论

Sheet2 是强正例资产，不是完整评估资产。

可用方式：

```text
Sheet2 做正例种子
Sheet1 做反例 / 不确定 / 历史 / 标签质量配平
Data Agent 做批量取证验证
Dennis Agent 做 evidence-based judgement
人工做最终确认
```

不能用法：

```text
只用 Sheet2 训练或回归
把 Sheet2 分布当全量盗号分布
把用户自述和人工备注直接当证据
把色情/招嫖内容发布直接等同 ATO 成立
```
