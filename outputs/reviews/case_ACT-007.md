# Case ACT-007 回归评审

## 原始问题

直播红包被大量群控设备抢，如何查和打？

## Skill 路由

- 主控 Skill：activity_anti_cheating_expert_skill
- 辅助 Skill：group_control_expert_skill、risk_governance_design_skill、evidence_decomposition_skill

## 回答

一句话判断：直播红包群控的核心不是“抢得快”，而是黑产批量调度账号/设备在红包发放窗口集中完成领取、提现或转卖，治理要围绕资金链和任务链分层，而不是只挡点击。

领域归类：活动反作弊。

风险类型：群控 / 小号 / 活动套利 / 可能混合真人验证。

黑产本质：
- 作恶方：红包羊毛团伙、真机/云手机群控团队、账号池运营者。
- 上游资源：批量账号、设备池、代理 IP、中控脚本、直播间目标列表、提现账户。
- 中游执行：监听红包发放，批量进入直播间，统一点击领取，必要时真人过验证。
- 下游变现：红包提现、账户余额转移、优惠权益售卖、平台补贴套利。
- 平台被利用环节：直播间红包发放机制、领取资格、设备/账号频控、提现结算。
- 最适合治理节点：领取资格和结算环节，辅以设备团组和收益聚集处置。

关键证据：
- 强证据：同批设备在红包窗口秒级进入/点击/退出；多账号共设备或设备轮换；账号-设备-IP-提现主体形成团组；点击路径和节奏高度一致；领取后提现或权益流向少量主体；发现云手机/模拟器/中控痕迹。
- 中证据：新号/低活号占比高；直播间停留短但红包命中率高；同 IP 段集中；任务完成时间窗口集中；多直播间重复抢同类红包。
- 弱证据：高频点击、设备聚集、领取成功率高、账号画像低质。不能单独等同群控。
- 反证 / 误判：明星/大促直播自然流量；主播提前预告导致集中进入；运营投放带来的新号；家庭/校园 NAT；内部测试；正常用户手速快。

补证动作：
- 查直播链路：进房、停留、互动、红包曝光、点击、领取、退出、提现。
- 查设备链路：指纹、模拟器/云手机、改机、设备复用、启动批次。
- 查收益链路：红包金额、提现账户、支付工具、权益转移、结算扣除。
- 查团组关系：账号-设备-IP-直播间-红包-提现主体。
- 查业务边界：主播预告、运营投放、活动规则、合法矩阵账号。

治理方案：
- 高准：封禁团伙账号，设备处置，冻结红包收益，提现拦截，异常收益回收。
- 中准：延迟发奖、限额、冷却期、强验证、领取资格降权、人工复核。
- 低准：加采、观察、进入监控池，不影响实时互动体验。
- 规则改造：单设备/单实名/单支付主体收益上限；红包随机化；领取资格与历史互动、可信设备、直播停留质量绑定。
- 业务协同：主播侧风险提示，红包预算分层，异常结算扣除，活动复盘。

灰度策略：
- 先在高资损直播间、高金额红包、历史高风险设备池灰度。
- 领取前用无感校验，领取后用延迟结算控制误伤。
- 高置信直接冻结收益，中置信延迟发放，低置信只观察。
- 留出正常热点豁免口径，监控客诉和主播收入影响。

评估指标：
- 红包资损率、风险领取占比、冻结/回收金额、团伙召回率、误伤率、领取成功率变化、直播互动损伤、客诉、黑产迁移到真人众包或协议抢领的比例。

可沉淀资产：
- 直播红包风险链路图、设备团组策略包、收益聚集图谱、活动结算风控模板、红包灰度 SOP。
