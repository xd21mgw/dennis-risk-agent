# 14 个疑似新注册后招嫖账号批量分层模板

## 1. 目标

先判断这 14 个账号是不是同一批高风险新号，而不是直接逐个做风控定性。

本模板用于：

- 批量分层。
- 找共性。
- 找可回捞子集。
- 找反例和混入样本。
- 再决定是否进入最小 DataAgent 取证。

## 3. 分层目标

### 3.1 先回答的不是“是不是盗号”

先回答：

1. 这批号是不是同源批量。
2. 这批号是不是同一注册窗口。
3. 这批号是不是同设备 / 同 IP / 同 UA / 同地区。
4. 这批号是不是同模板作恶。
5. 这批号里是否混入反例、历史号或不确定样本。

### 3.2 再决定要不要查数

如果批量特征成立，再进入最小 DataAgent 取证。

## 4. 建议分层维度

### 4.1 发生方式分层

- 新注册后快速作恶。
- 新注册后仅登录未明显作恶。
- 新注册后先养号再作恶。
- 不确定 / 证据不足。

### 4.2 下游作恶方式分层

- 招嫖内容发布。
- 私信 / 评论 / 关注滥用。
- 导流 / 私域承接。
- 爬虫 / 接口访问 / 资产窃取。
- 活动套利 / 抢福利。
- 仅登录控制，未观测到明显作恶。
- 未验证 / 权限不足。

### 4.3 风险强度分层

- 高置信正例。
- 可疑批次。
- 反例。
- 待补证样本。
- 混入样本。

## 6. 推荐的优先分层规则

### 6.1 第一层：是否同源

优先看：

- 注册时间是否集中。
- 首登时间是否集中。
- 设备是否集中。
- IP / UA / 地区是否集中。
- 是否命中同类账号安全风险信号。

### 6.2 第二层：是否快速作恶

优先看：

- 注册后多久开始异常行为。
- 首登后多久开始异常行为。
- 是否存在“注册即作恶”。

### 6.3 第三层：是否同模板

优先看：

- 内容模板是否相似。
- 动作顺序是否相似。
- 是否都落到同一种下游作恶方式。

### 6.4 第四层：是否混入其他样本

优先看：

- 是否有只注册未作恶的号。
- 是否有历史号。
- 是否有不确定样本。
- 是否有误报样本。

## 8. 后续最小 DataAgent 取证入口

如果批量分层后要查数，优先只查最小证据：

1. 注册时间。
2. 首登时间。
3. 首发时间。
4. 注册 / 登录设备。
5. 注册 / 登录 IP。
6. UA / 地区。
7. 风控策略命中。
8. 是否有登录后下游作恶。

不默认：

- 长周期扩窗。
- 大样本回捞。
- 多表复杂 join。

## 9. 结论

这 14 个账号更适合先做批量分层，而不是逐个单 case 解释。

原因：

- 你当前原始意图是“是不是一批新注册后立刻作恶的垃圾号”。
- 先分层能更快区分同源批量、混入样本和反例。
- 分层结果能直接指导后续最小取证问题。
