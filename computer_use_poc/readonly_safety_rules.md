# 只读安全规则

## 1. 基本原则

computer use 只能执行只读页面查询和观察，不得执行任何会改变平台状态的动作。

## 2. 禁止点击的动作

禁止点击或触发以下按钮 / 链接 / 菜单：

- 处置
- 封禁
- 解封
- 提交
- 审批
- 保存
- 确认
- 删除
- 修改
- 导出
- 批量下载
- 批量操作
- 策略上线
- 策略下线
- 熔断
- 回滚
- 权限申请提交

如果页面出现上述按钮，只记录“存在风险按钮”，不得点击。

## 3. 权限边界

- 不绕过权限。
- 无权限时停止查询。
- 登录态失效时停止查询。
- VPN / 办公网不可用时停止查询。
- 不尝试切换账号、模拟登录、绕过二次验证。

## 4. 高敏字段处理

页面出现高敏字段时：

- 只记录字段是否可见。
- 默认不记录具体值。
- 用户名、手机号、设备 ID、IP、昵称、快手号、实名信息等默认 `redacted`。
- 脱敏手机号也不要直接输出具体脱敏串，统一写 `visible_masked_value_redacted` 或 `masked_redacted`。
- 不输出截图中的个人信息明文。
- 不截图保存明文敏感内容。
- 不复制手机号、身份证、实名信息、token、cookie、会话标识等明文。

## 5. 查询规模限制

- 只允许单个 `user_id` 查询。
- 不批量查询。
- 不导出结果。
- 不翻页抓取大规模明细。

## 6. 输出边界

computer use 输出只作为 observation。

风险结论必须由 Dennis Risk Agent 结合多证据判断，不得由 computer use 直接输出最终风控定性。

## 7. 停止条件

出现以下情况必须停止：

- 无权限。
- 未登录。
- 页面要求提交申请或审批。
- 出现写操作风险。
- 页面结构不确定且可能误触写操作。
- 平台提示高敏合规风险。
