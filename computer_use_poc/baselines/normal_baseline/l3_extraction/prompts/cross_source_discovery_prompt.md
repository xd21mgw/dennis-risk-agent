# Cross-source Discovery Prompt

Use only high-value per-action features and supporting signals. Do not ingest the
full raw bundle at this stage.

Look for cross-source chains such as:

- profile/social funnel + content/collect/private-message diversion
- login/client version + device environment + social behavior
- app/toolchain signals + account behavior
- relation graph + same-device/account cluster + behavior rhythm

Every chain hypothesis must preserve missing data and replay requirements.
