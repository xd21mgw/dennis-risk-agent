# 待确认字段与平台不确定项

## 1. 跨平台待确认

| 项目 | 涉及平台 | 不确定点 | 建议确认方式 |
|---|---|---|---|
| user_id / author_id / User ID 主体差异 | 全平台 | 不同页面主体可能是作者、登录用户、被查用户 | 找平台字段字典确认 |
| device_id / DID / deviceId 归一 | 档案中心、登录日志、设备攻防、行为细查 | 是否同一设备标识体系，空 DID 如何解释 | 用同一 case 交叉验证 |
| IP 字段口径 | 档案中心、登录日志、设备攻防 | user IP、service caller IP、device network IP 混用风险 | 标注用户侧/服务侧/设备侧 |
| 时间字段精度和时区 | 全平台 | 秒级/毫秒级/页面时间不一致 | 确认平台时区和导出格式 |
| risk_label / mark_code 字典 | 档案中心、设备攻防、RAP | 编码含义、版本和适用范围 | 拉取内部字典 |
| 策略名是否可对外展示 | 天狮、RAP | 具体策略名是否可进入长期知识库 | 按防过拟合规则抽象 |

## 2. 档案中心待确认

| 新版/旧版审核日志 | 字段差异和长期保留策略需确认 |
| 手机号明文查看 | 权限、审计和合规边界需确认 |
