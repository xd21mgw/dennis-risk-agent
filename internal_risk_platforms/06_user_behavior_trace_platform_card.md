# 用户行为细查平台（埋点行为分析）

## 1. 平台一句话定位

用户行为细查平台用于查询用户或设备的前端行为序列、页面轨迹、停留、session、设备环境和埋点详情。

## 2. 平台能力边界

### 2.1 能查什么

- 用户/设备维度的行为序列和行为详情。
- 用户属性、活跃天数、设备属性、使用时长趋势。
- 前端埋点事件、页面 URL、点击位置、停留时长、设备/网络/APP 版本。
- 多设备行为筛选、设备型号、session_id、联网方式。
- 前后端链路一致性的前端侧证据。

### 2.2 不能查什么

- 不适合查登录 token、OAuth、扫码等后端原始链路。
- 不适合查设备底层攻防、模拟器、刷机、APK 风险。
- 不适合查策略命中和策略配置。
- 不适合替代 Hive 离线大盘。
- 行为记录区可能需要手动导入数据，非默认自动展示。

### 2.3 应转向哪些平台

| 需求 | 应转向平台 |
|---|---|
| 后端登录 / token / OAuth / 高危接口 | 用户登录统一日志 |
| 设备底层风险 | 设备攻防基建平台 |
| 策略命中 / 策略配置 | 天狮策略引擎 |
| 用户/内容/处罚事实 | 档案中心 / 风险运营中心 |
| 批量行为聚合 | DataAgent / Hive |

## 3. 典型查询对象

| 查询对象 | 输入方式 | 适用问题 | 注意事项 |
|---|---|---|---|
| user_id | 顶部搜索框 / filtersType=userId | 用户行为链路、前端操作核验 | 最常用 |
| device_id / DID | 顶部搜索框切换 | 设备行为、跨账号设备行为 | 需和设备攻防字段统一 |
| 时间范围 | 日期筛选 | 事件窗口内行为 | 太宽会噪声大 |
| 目标行为 | 行为记录筛选 | 特定页面/动作 | 需知道埋点或行为名 |
| 设备筛选 | 行为记录区设备下拉 | 多设备时定位 | 多设备时必须使用 |

## 4. 页面 / 模块结构

| 页面模块 | 核心功能 | 关键字段 | 常用场景 | 优先级 |
|---|---|---|---|---|
| 顶部操作区 | 平台选择、用户/设备切换、搜索、时间筛选 | user_id, device_id, time_window | 查询入口 | P0 |
| 用户属性及时长区 | 基础信息、地区、注册、粉丝、月活跃、设备属性、使用时长 | region, register_time, active_days | 真人行为背景 | P1 |
| 行为记录区 | 行为列表，需手动导入 | event_time, event_name, device_id | 行为链路 | P0 |
| 行为详情页 | 单条行为全量参数 | page_url, session_id, device_model, network_type | 前端行为解释 | P0 |
| 环境信息 | 设备/网络/APP 版本 | app_version, os_version, device_model | 设备和环境交叉验证 | P1 |

## 5. 核心字段字典

| 字段名 | 页面展示名 | 含义 | 风控解释 | 适用场景 | 可信度/注意事项 |
|---|---|---|---|---|---|
| user_id | 用户ID | 用户唯一标识 | 行为主体 | 全场景 | 高可信 |
| device_id | 设备ID | 行为设备 | 多设备切换、设备一致性 | 账号安全、群控 | 需与设备攻防统一 |
| region | 地区 | 用户地区 | 与登录 IP/设备位置交叉验证 | 账号安全 | 地区口径需确认 |
| register_time | 注册时间 | 账号创建时间 | 新注册异常、假量 | 假量/裂变 | 需与档案中心对齐 |
| active_days | 月活跃天数 | 活跃程度 | 真人行为背景 | 真人验证、假量 | 不能单独定性 |
| device_attributes | 设备属性 | 设备类型、归因渠道等 | 渠道和设备来源线索 | 假量、渠道风险 | 字段口径需确认 |
| event_time | 行为时间 | 前端行为发生时间 | 与后端日志对齐 | 协议上号、行为链路 | 埋点延迟需考虑 |
| event_name | 行为名称 | 埋点/行为名 | 判断是否有对应前端行为 | 协议上号、活动假量 | 行为字典需确认 |
| page_url | 页面URL | 前端页面路径 | 是否到达敏感页面 | 内容、活动、账号安全 | 需业务解释 |
| session_id | 会话ID | 前端会话 | 频繁切换、会话断裂 | 协议上号、自动化 | session 口径需确认 |
| device_model | 机型 | 行为设备型号 | 与登录/设备平台交叉验证 | 账号安全、群控 | 设备名可能归一化 |
| app_version | APP版本 | 客户端版本 | 版本一致性 | 协议上号、破解包 | 需和设备攻防对齐 |
| network_type | 联网方式 | WiFi/蜂窝等 | 网络环境 | 自动化/真人行为 | 辅助字段 |
| stay_duration | 停留时长 | 页面停留时间 | 真人行为或脚本快进线索 | 反爬、活动假量 | 需分布校准 |

## 6. 通用适用场景

- ATO / 账号安全：适用。查高危操作前后的前端行为链路，ATO 是典型用例之一。
- 群控 / 号商：部分适用。查多账号行为相似性、设备切换和行为节奏。
- 协议上号：适用。查后端有操作但前端无对应埋点的反证。
- 反爬 / 资产抓取：适用。查真人访问路径、前端行为是否缺失、自动化行为。
- 内容风险：部分适用。查发布/编辑/浏览链路，不查内容审核事实。
- 假量 / 裂变：适用。查拉新后是否有真实消费、停留和互动。
- 社交骚扰：部分适用。查私信/关注/评论前端行为链路，需结合内容/举报。
- 策略误伤 / 策略归因：部分适用。提供用户真实行为反证，策略归因转天狮。

## 7. 风险场景覆盖矩阵

| 风险场景 | 是否适用 | 适用方式 | 关键字段 / 模块 |
|---|---|---|---|
| ATO / 账号安全 | 适用 | 查敏感操作前后是否有真人行为 | event_time, event_name, session_id |
| 群控 / 号商 | 部分适用 | 行为同步、节奏相似、设备切换 | event_name, device_id |
| 协议上号 | 适用 | 前端无行为与后端有操作对比 | 行为记录区、page_url |
| 反爬 / 资产抓取 | 适用 | 真人访问验证、前端链路缺失 | stay_duration, page_url |
| 内容风险 | 部分适用 | 发布/编辑链路 | event_name, page_url |
| 假量 / 裂变 | 适用 | 拉新后真实消费和留存行为 | active_days, event_name |
| 社交骚扰 | 部分适用 | 社交动作路径 | event_name, page_url |
| 策略误伤 / 策略归因 | 部分适用 | 行为反证 | session_id, event_time |

## 8. 典型查询路径

### 8.1 行为链路还原

- 输入：user_id + 可疑时间窗口
- 查询模块：用户行为序列 → 行为详情 → 环境信息
- 关键字段：event_time, event_name, page_url, session_id, device_model
- 输出结论：是否存在连续前端操作链路、是否直奔敏感功能、是否像真人
- 下一步平台：用户登录统一日志查后端登录/高危接口；设备攻防查设备可信

### 8.2 协议上号识别

- 输入：user_id + 后端操作时间
- 查询模块：行为记录区按时间检索
- 关键字段：event_time, event_name, page_url, session_id
- 输出结论：后端有操作时前端是否有对应页面/行为
- 下一步平台：用户登录统一日志确认后端操作；DataAgent/Hive 批量验证

### 8.3 假量 / 裂变真实行为验证

- 输入：user_id / 样本用户 + 活动时间窗口
- 查询模块：用户属性及时长 → 行为记录 → 行为详情
- 关键字段：active_days, stay_duration, event_name, device_attributes
- 输出结论：拉新后是否有真实消费、停留、互动，而非只完成任务
- 下一步平台：DataAgent/Hive 做批量后验；风险运营中心查用户画像

## 9. Agent 路由规则

- 问题包含“前端有没有操作 / 埋点 / 行为链路 / 真人行为 / 自动化 / 后端有请求但前端无行为”时，优先查用户行为细查。
- 如果问题是 token/OAuth/扫码原始链路，优先用户登录统一日志，不要用行为细查替代。
- 如果问题是设备可信，转设备攻防。
- 如果问题是策略命中，转天狮。

## 10. Agent 解释规则

- 前端无行为是协议/自动化线索，但也可能是埋点缺失、版本差异、数据导入问题。
- 有前端行为不等于真人，需看行为连续性、停留、页面路径和环境一致性。
- 行为链路能证明“用户端发生过什么”，不能单独证明账号归属或攻击者身份。
- session 频繁变化是线索，不是强结论。
- 行为记录区需手动导入时，空结果不能解释为无风险。
