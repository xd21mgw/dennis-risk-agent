# 内部风控平台路由索引

## 1. 平台分层总表

| 平台 | 能力层 | 一句话定位 | 优先适用 | 不适合 |
|---|---|---|---|---|
| 档案中心 | 综合事实档案 | 查用户、视频、直播、举报、审核、设备关联等基础事实 | 用户/内容现状、风控状态、判罚、同设备聚集 | 全端登录明细、实时 token、设备底层指纹、策略配置 |
| 风险运营中心 RAP | 风控分析 / 扩量 | 查风控深度画像、策略详情摘要、举报分析、关联账号滚雪球 | 综合研判、关联扩量、举报归因、案例留存 | 实时日志、设备底层、策略上线 |
| 设备攻防基建平台 | 设备可信 / 设备图谱 | 查设备真实性、设备风险标签、安装 APP、关联图谱、底层 SDK 指纹 | 设备风险、群控、模拟器、刷机、破解包、设备扩量 | 登录链路、策略归因、离线大盘 |
| 用户登录统一日志 | 全端登录 / 高危操作日志 | 查 APP/PC/小程序等全端登录、OAuth、扫码、token、高危接口调用 | 异常登录、协议上号、token/session、高危操作 | 设备底层、用户画像、内容/举报、策略配置 |
| 天狮策略引擎 | 策略归因 / 策略生命周期 | 查事件、特征、策略、命中、版本、熔断、报警 | 策略误伤、策略命中归因、线上风控策略解释 | 原始登录日志、设备底层、内容事实 |
| 用户行为细查平台 | 前端行为 / 埋点轨迹 | 查用户/设备前端行为序列、页面、停留、session、设备环境 | 行为链路、真人行为验证、自动化、活动假量、协议反证 | token/OAuth 原始链路、设备底层、策略配置 |
| DataAgent / Hive | 离线数仓分析 | 生成或执行 Hive/公司数仓取数分析、聚合、趋势、批量验证 | 离线大盘、批量样本、趋势/归因、跨表聚合 | 实时日志、在线工具页面、所有风控工具的替代品 |

## 2. 问题类型 → 优先平台 → 补充平台

| 问题类型 | 优先平台 | 补充平台 | 说明 |
|---|---|---|---|
| 账号异常 / ATO / 异常登录 | 用户登录统一日志 | 档案中心、设备攻防、用户行为细查、天狮 | ATO 是账号安全典型用例，不是平台唯一用途 |
| token / OAuth / 扫码 / 高危操作 | 用户登录统一日志 | 天狮、用户行为细查、设备攻防 | 先看全端登录和高危接口，再看策略和设备可信 |
| 群控 / 号商 / 设备聚集 | 设备攻防基建平台 | 档案中心、风险运营中心、天狮 | 设备图谱和关联账号是主入口 |
| 协议上号 / 后端有请求前端无行为 | 用户登录统一日志 | 用户行为细查、设备攻防、天狮 | 先确认后端日志，再查前端埋点反证 |
| 反爬 / 资产抓取 / 外部跟价 | 用户行为细查 | 用户登录统一日志、天狮、DataAgent/Hive | 平台页面对资产抓取覆盖有限，大盘需 DataAgent/Hive |
| 内容风险 / 视频 / 直播 / 评论 | 档案中心 | 风险运营中心、天狮、用户行为细查 | 档案中心先查内容和审核事实 |
| 假量 / 裂变 / 活动作弊 | 用户行为细查 | 风险运营中心、档案中心、DataAgent/Hive、天狮 | 行为链路和后验大盘需要结合 |
| 社交骚扰 / 私信 / 评论导流 | 档案中心 | 风险运营中心、用户行为细查、天狮 | 先查用户/内容/举报，再看行为链路 |
| 策略误伤 / 策略归因 | 天狮策略引擎 | 档案中心、风险运营中心、用户登录统一日志 | 策略命中不是最终结论，需回到事实证据 |
| 批量样本验证 / 离线趋势 | DataAgent / Hive | 以上页面工具按样本抽查 | DataAgent 只负责数仓取数分析，不替代在线工具 |

## 3. Agent 默认路由规则

0. 当用户问题涉及内部平台查询、证据补充、风险研判路径、平台手脚选择时，优先读取本文件；需要具体字段和页面解释时，再读取对应平台卡；涉及跨平台流程时，读取 `90_cross_platform_investigation_paths.md`。
1. 用户问“这个用户 / 内容 / 账号现在是什么状态”：先查档案中心。
2. 用户问“为什么被策略命中 / 有没有误伤”：先查天狮策略引擎，再回查档案中心和原始日志。
3. 用户问“是不是新设备 / 模拟器 / 群控 / 设备聚集”：先查设备攻防基建平台。
4. 用户问“扫码 / OAuth / token / 高危操作 / 协议上号”：先查用户登录统一日志。
5. 用户问“前端有没有行为 / 行为链路是否像真人”：先查用户行为细查平台。
6. 用户问“批量样本 / 趋势 / 大盘 / 聚合”：生成 DataAgent / Hive 查询建议。
7. 非明确查数问题，先给平台路由和取证计划，不假装已有查询结果。

## 4. 平台之间的跳转规则

| 当前发现 | 下一步平台 | 跳转理由 |
|---|---|---|
| 档案中心发现同设备多账号 | 设备攻防基建平台 | 验证设备可信、图谱扩散、封禁比例 |
| 档案中心查不到 PC/小程序登录 | 用户登录统一日志 | 档案中心用户分析主要覆盖 APP 端日志 |
| 风险运营中心看到策略详情摘要 | 天狮策略引擎 | 查策略条件、特征值、版本和命中归因 |
| 设备攻防发现新设备 / 风险设备 | 用户登录统一日志 | 验证该设备是否参与登录 / 授权 / 高危操作 |
| 用户登录统一日志发现 OAuth / token / 高危接口 | 用户行为细查平台 | 查前端是否有对应行为链路 |
| 用户行为细查发现前端行为缺失 | 用户登录统一日志 / DataAgent | 查后端操作是否真实存在，批量验证用 Hive |
| 天狮发现策略命中或误伤疑点 | 档案中心 / 用户登录统一日志 | 回看用户事实、登录链路、操作结果 |
| 页面工具无法覆盖批量问题 | DataAgent / Hive | 做数仓聚合、趋势和样本批量分析 |

## 5. DataAgent / Hive 边界说明

- DataAgent 主要用于 Hive / 公司数仓取数分析、SQL 生成、批量样本聚合、趋势和归因。
- DataAgent 不是所有在线风控工具的替代品，不能覆盖所有实时日志、所有页面工具、所有权限受限字段。
- DataAgent 返回 SQL-only / partial / no_permission / timeout 时，只能作为取证未完成或证据不足，不能当作反证。
- 需要页面级字段、截图锚点、策略配置、设备图谱、实时交互时，仍应路由到对应平台。
