# 用户登录统一日志（用户中心智能工作台）

## 1. 平台一句话定位

用户登录统一日志用于查询用户全端登录、业务鉴权、token/session、OAuth/扫码和高危接口调用日志。

## 2. 平台能力边界

### 2.1 能查什么

- 用户全端登录记录，覆盖 APP、PC、小程序及其他端的账号登录相关日志。
- 增长登录相关日志、账号登录相关日志、业务鉴权日志、高危接口调用日志。
- token 生成、刷新、鉴权、session 相关线索。
- OAuth、扫码登录、密码/短信登录、高危操作调用。
- 日志详情 JSON：serviceKsn、callerKsn、method、request、action、timestamp 等。

### 2.2 不能查什么

- 不适合查用户画像、内容、举报、审核、判罚全量。
- 不适合查设备底层可信、模拟器、刷机、APK 风险。
- 不适合查策略配置、特征表达式和策略版本。
- 不适合替代 Hive 离线大盘和批量聚合。

### 2.3 应转向哪些平台

| 需求 | 应转向平台 |
|---|---|
| 用户画像 / 内容 / 举报 / 审核事实 | 档案中心 / 风险运营中心 |
| 设备可信 / APK / 模拟器 / 图谱 | 设备攻防基建平台 |
| 策略命中和策略配置 | 天狮策略引擎 |
| 前端行为和埋点轨迹 | 用户行为细查平台 |
| 批量趋势和离线聚合 | DataAgent / Hive |

## 3. 典型查询对象

| 查询对象 | 输入方式 | 适用问题 | 注意事项 |
|---|---|---|---|
| User ID | 搜索框 | 登录链路、高危操作、token/session | 必填主锚点 |
| DID | 搜索框 | 设备维度过滤 | 可选；字段可能为空 |
| 时间范围 | 开始/结束时间 | 事件窗口追溯 | 必须明确，避免查询过宽 |
| 日志来源 | 多选框 | 增长登录、账号登录、鉴权、高危接口 | 选择错误会漏证据 |
| Query 关键词 | 搜索框 | token/auth/session/method 过滤 | 只能辅助，不宜过窄 |

## 5. 核心字段字典

| 字段名 | 页面展示名 | 含义 | 风控解释 | 适用场景 | 可信度/注意事项 |
|---|---|---|---|---|---|
| user_id | User ID | 用户唯一标识 | 查询主体 | 全场景 | 高可信 |
| did | DID | 设备标识 | 设备过滤和链路关联 | 账号安全、协议上号 | 可能为空 |
| start_time | 开始时间 | 查询起点 | 事件窗口左边界 | 全日志查询 | 时间过宽成本高 |
| end_time | 结束时间 | 查询终点 | 事件窗口右边界 | 全日志查询 | 时间过窄可能漏 |
| log_source | 日志来源 | 日志类型 | 选择登录/鉴权/高危接口 | 账号安全、协议上号 | 需按问题选择 |
| query_keyword | Query | 关键词过滤 | token/auth/session 等定位 | token/session | 过窄会漏 |
| timestamp | 时间 | 日志发生时间 | 与异常事件对齐 | 全场景 | 高可信 |
| tag | 标签 | 日志类型标签 | 高危接口/账号登录/鉴权 | 风险链路 | 标签需结合 method |
| method | Method | 接口方法名 | 识别登录、授权、写入、高危操作 | 协议上号、账号安全 | 需方法字典 |
| request | 请求参数 | 完整请求体 | 识别操作对象和参数 | 高危操作、token | 可能含敏感字段 |
| action | 操作结果 | allow / deny 等 | 成功/拒绝，判断操作是否生效 | 高危操作 | deny 不是无风险 |
| callerKsn | 调用方KSN | 调用方服务 | 判断来源服务或客户端链路 | 协议上号、归因 | 需内部服务知识 |
| callerIp | 调用方IP | 调用方内网 IP | 服务链路追溯 | 策略归因 | 多为内网，不等于用户 IP |
| serviceKsn | 服务KSN | 被调用服务 | 服务端路径 | 技术归因 | 风控解释有限 |

## 6. 通用适用场景

- ATO / 账号安全：适用。查异常登录、OAuth、扫码、高危操作、token/session，ATO 是典型用例之一。
- 群控 / 号商：部分适用。查批量账号是否存在类似登录/鉴权模式；聚集扩量需其他平台。
- 协议上号：适用。查后端登录/鉴权/高危接口，确认是否有前端缺失的后端操作。
- 反爬 / 资产抓取：部分适用。可查账号鉴权和接口调用线索；资产访问需业务日志或 DataAgent/Hive。
- 内容风险：部分适用。可查发布前后的账号操作，不查内容本身。
- 假量 / 裂变：部分适用。可查登录/鉴权和高危动作，活动链路需 DataAgent/Hive。
- 社交骚扰：部分适用。可查账号和高危调用，不查私信内容本身。
- 策略误伤 / 策略归因：部分适用。可查被策略前后的真实操作链路，策略条件转天狮。

| 风险场景 | 是否适用 | 适用方式 | 关键字段 / 模块 |
|---|---|---|---|

| 群控 / 号商 | 部分适用 | 对比多账号登录方式和鉴权行为 | timestamp, method, did |

| 反爬 / 资产抓取 | 部分适用 | 查鉴权链路和账号操作 | 业务鉴权日志 |
| 内容风险 | 部分适用 | 查发布前后登录/操作链路 | method, timestamp |
| 假量 / 裂变 | 部分适用 | 查账号参与前后登录鉴权 | 账号登录、业务鉴权 |

| 策略误伤 / 策略归因 | 部分适用 | 还原用户真实操作 | action, request, timestamp |

## 8. 典型查询路径

### 8.1 异常登录 / 高危操作链路

- 输入：user_id + 可疑时间窗口
- 查询模块：搜索条件 → 账号登录相关日志 + 高危接口调用日志 → 详情 JSON
- 关键字段：timestamp, tag, method, request, action, callerKsn
- 输出结论：是否存在登录/授权/高危操作、操作是否成功、调用方是什么
- 下一步平台：设备攻防查设备可信；用户行为细查查前端链路；天狮查策略归因

### 8.2 token/session 线索查询

- 输入：user_id + token/session 相关时间窗口
- 查询模块：业务鉴权日志 → Query 关键词 token/auth/session
- 关键字段：method, request, action, timestamp
- 输出结论：是否有 token 生成、刷新、鉴权异常线索
- 下一步平台：用户行为细查验证前端行为；DataAgent/Hive 做离线批量分析

### 8.3 协议上号核查

- 输入：user_id + 后端异常操作时间
- 查询模块：账号登录 / 业务鉴权 / 高危接口
- 关键字段：method, tag, action, did, request
- 输出结论：是否存在后端登录/鉴权/敏感操作
- 下一步平台：用户行为细查检查前端是否有对应埋点；设备攻防查设备可信

## 9. Agent 路由规则

- 问题包含“token / session / OAuth / 扫码 / Web 登录 / 高危接口 / action=allow/deny / 协议上号”时，优先查用户登录统一日志。
- 档案中心查不到 PC/Web/小程序登录时，转用户登录统一日志。
- 如果需要解释策略命中原因，转天狮；如果需要设备可信，转设备攻防；如果要前端行为，转用户行为细查。

## 10. Agent 解释规则

- `action=allow` 支持操作成功，`action=deny` 支持被拒绝；但 deny 不等于无风险，可能是攻击尝试。
- method 命中 OAuth/扫码/token 只是链路线索，需要结合设备、IP、前端行为和下游操作。
- callerKsn/callerIp 多为服务侧信息，不能直接解释为攻击者外网 IP。
- DID 为空不等于没有设备，可能是日志源未上报。
- 查不到日志不等于无风险，可能是时间窗、日志源、权限或数据覆盖问题。
