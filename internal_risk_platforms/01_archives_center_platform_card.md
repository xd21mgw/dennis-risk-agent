# 档案中心

## 1. 平台一句话定位

档案中心是一站式事实档案平台，用于查询用户、视频、直播、私信、说说、举报、审核日志、风控状态和基础设备关联。

## 2. 平台能力边界

### 2.1 能查什么

- 用户基础画像、手机号、快手号、注册/登录信息、风控状态、实时负向。
- 审核日志、打标日志、判罚记录、新旧版审核明细。
- 用户分析页中的 APP 端核心操作日志：启动登录、注册绑定、重置密码、用户设置、扫码、注销、冻结。
- 视频作品集、视频详情、视频 meta、直播基础信息、评论和举报。
- 同设备注册 / 登录用户，支持设备聚集初筛。

### 2.2 不能查什么

- 不完整覆盖 PC、小程序、Web 等全端登录链路。
- 不适合查 token、OAuth、扫码、业务鉴权等原始日志明细。
- 不适合查设备底层指纹、模拟器、刷机、APK 风险。
- 不适合做 Hive 离线大盘、批量聚合统计。
- 不直接给最终处置结论。

### 2.3 应转向哪些平台

| 需求 | 应转向平台 |
|---|---|
| 全端登录 / token / OAuth / 高危接口 | 用户登录统一日志 |
| 设备可信 / 模拟器 / 刷机 / 关联图谱 | 设备攻防基建平台 |
| 策略命中原因和策略配置 | 天狮策略引擎 |
| 批量样本 / 离线趋势 | DataAgent / Hive |
| 前端行为链路 | 用户行为细查平台 |

## 5. 核心字段字典

| 字段名 | 页面展示名 | 含义 | 风控解释 | 适用场景 | 可信度/注意事项 |
|---|---|---|---|---|---|
| user_id | 用户ID | 用户唯一标识 | 串联画像、行为、处罚核心锚点 | 全场景 | 高可信 |
| device_id | 设备ID | 设备唯一标识 | 多账号共用设备可提示群控/号商；新设备可提示异常登录 | 账号安全、群控、假量 | 深度风险需设备攻防验证 |
| phone_number | 手机号 | 注册/绑定手机 | 同手机号多账号、换绑可作为账号安全线索 | 账号安全、号商 | 明文权限受限 |
| last_login_time | 最近登录时间 | 最近登录时间 | 定位异常窗口 | 账号安全、协议上号 | 只代表最近一次，不代表完整链路 |
| last_login_ip | 最近登录IP | 最近登录网络地址 | 异地、同IP聚集线索 | 账号安全、群控、反爬 | IP 地理有误差 |
| punish_status | 风控状态/实时负向 | 当前生效处罚 | 判断是否已处置或存在历史风险 | 全场景 | 处罚不等于最终风险事实 |
| punish_code | 操作结果 | 处罚编码 | 区分处罚类型 | 内容风险、账号安全 | 需状态码字典 |
| mark_code | 风控标签 | 风险标签编码 | 精细风险分类 | 全场景 | 不能单独强结论 |
| operation_type | 操作类型 | APP 端操作类别 | 识别登录、注册、重置、扫码、注销、冻结等敏感操作 | 账号安全、协议上号 | 仅覆盖 APP 端为主 |
| operation_url | 操作URL | 接口请求路径 | 识别登录方式和操作类型 | 账号安全、行为链路 | URL 含义需结合接口口径 |
| operation_result | 操作结果 | 成功/失败 | 失败多可提示暴力尝试或误操作 | 账号安全 | 失败不等于攻击 |
| user_ip_desc | 用户IP描述 | IP + 地理位置 | 异地、聚集、地理冲突线索 | 账号安全、群控 | IP 地理可能偏差 |
| photo_id | 视频ID | 视频唯一标识 | 内容和发布链路锚点 | 内容风险、假量 | 高可信 |
| upload_time | 发布时间 | 视频上传时间 | 批量上传、异常时间窗 | 内容风险、假量 | 精度以页面为准 |
| deviceId | 视频 meta 设备ID | 上传设备 | 与用户设备交叉验证 | 内容风险、账号安全 | 需与档案设备字段统一 |
| audit_time | 审核时间 | 审核操作时间 | 与可疑事件对齐 | 内容风险、策略误伤 | 旧版日志更全 |
| remark | 审核备注 | 审核说明 | 人工判断线索 | 内容风险、误伤复盘 | 备注不是事实证据 |

## 6. 通用适用场景

- ATO / 账号安全：适用。查账号状态、登录注册、APP 端高危操作、换绑/注销、同设备关联。ATO 是账号安全典型用例之一。
- 群控 / 号商：适用。查同设备注册/登录、注册时间、同IP、账号状态。
- 协议上号：部分适用。可查 APP 端行为和账号状态；全端登录需转用户登录统一日志。
- 反爬 / 资产抓取：仅部分适用。可查用户/内容事实，不适合查资产访问链路。
- 内容风险：适用。视频/直播/评论、审核日志、举报。
- 假量 / 裂变：部分适用。可查粉丝、作品、同设备和举报；大盘需 DataAgent/Hive。
- 社交骚扰：适用。查用户状态、举报、评论/私信线索。
- 策略误伤 / 策略归因：部分适用。查判罚和审核事实；策略条件需转天狮。

## 8. 典型查询路径

### 8.1 账号安全 / 异常登录路径（ATO 是典型用例之一）

- 输入：user_id
- 查询模块：用户主页 → 用户信息页 → 用户分析页 → 同设备登录/注册
- 关键字段：punish_status, last_login_time, last_login_ip, device_id, operation_type, operation_result, user_ip_desc
- 输出结论：账号状态、APP 端敏感操作、设备/IP 是否异常、是否有同设备聚集
- 下一步平台：用户登录统一日志查全端登录；设备攻防查设备可信；天狮查策略归因

### 8.2 群控 / 号商初筛路径

- 输入：user_id 或 device_id
- 查询模块：同设备注册/登录用户 → 用户信息页 → 审核日志
- 关键字段：same_device_register_users, same_device_login_users, register_ip, login_ip, punish_status
- 输出结论：设备聚集规模、负向账号占比、注册/登录集中度
- 下一步平台：设备攻防基建平台做设备图谱；风险运营中心滚雪球扩量

### 8.3 内容风险路径

- 输入：photo_id / liveStreamId / author_id
- 查询模块：视频主页 → 视频详情 → 视频 meta → 审核日志 / 举报搜索
- 关键字段：photo_id, author_id, upload_time, video_status, mark_code, audit_time, remark
- 输出结论：内容状态、审核依据、上传环境、举报风险
- 下一步平台：风险运营中心做举报深度分析；天狮查策略命中

### 8.4 策略误伤事实核对路径

- 输入：user_id / photo_id / punish_code
- 查询模块：用户信息页 → 审核日志新版/旧版 → 打标日志
- 关键字段：punish_status, punish_code, audit_time, operation, remark
- 输出结论：是否存在处罚事实、人工/机器操作、备注依据
- 下一步平台：天狮查策略条件和特征值；风险运营中心查解封详情

## 9. Agent 路由规则

- 需要查用户、内容、直播、举报、审核、处罚事实时，优先路由到档案中心。
- 需要单点事实核对时，档案中心是第一站。
- 问题包含“这个用户状态 / 这个视频 / 有没有被罚 / 审核记录 / 同设备”时，优先查档案中心。
- 如果问题是“为什么命中策略”，不要停在档案中心，应转天狮。
- 如果问题是“token / OAuth / Web 登录”，不要停在档案中心，应转用户登录统一日志。

## 10. Agent 解释规则

- 同设备多账号是聚集线索，不等于群控；需要看设备可信、行为同步、收益聚集。
- 登录 IP 与注册 IP 不同是风险线索，不等于盗号；需结合历史设备、登录方式、高危操作。
- mark_code / punish_code 是平台标签或处置事实，不等于最终风险定性。
- 审核备注只能作为人工线索，不应作为 strong evidence。
- 用户分析页高危操作日志仅覆盖 APP 端为主；缺 PC/Web/小程序链路时必须降级。
