# 天狮策略引擎

## 1. 平台一句话定位

天狮策略引擎是风控策略全生命周期平台，用于查询事件、特征、策略配置、策略命中、版本、熔断、报警和归因。

## 2. 平台能力边界

### 2.1 能查什么

- 事件接入、事件 ID、事件字段和事件触发入口。
- 特征配置：特征名、表达式、特征值、加工逻辑。
- 策略配置：策略名、条件、结果、版本、状态、优先级、保护配置。
- 策略树绑定、上线、保护、优先级。
- 事件查询 / 归因：某用户在某事件下命中的策略、特征值、命中详情。
- 策略熔断、策略报警、命中量波动。

### 2.2 不能查什么

- 不适合查原始登录 token / OAuth / 扫码日志。
- 不适合查设备底层 SDK 指纹、模拟器、APK 风险。
- 不适合查用户内容、举报、审核事实。
- 不适合替代事实研判；策略命中不是最终风险结论。

### 2.3 应转向哪些平台

| 需求 | 应转向平台 |
|---|---|
| 登录 / token / OAuth / 高危接口 | 用户登录统一日志 |
| 设备底层、模拟器、APK 风险 | 设备攻防基建平台 |
| 用户 / 内容 / 举报 / 审核事实 | 档案中心 / 风险运营中心 |
| 前端行为链路 | 用户行为细查平台 |
| 批量离线评估 | DataAgent / Hive |

## 3. 典型查询对象

| 查询对象 | 输入方式 | 适用问题 | 注意事项 |
|---|---|---|---|
| 事件名 / 事件ID | 事件列表 / 事件查询 | 哪个事件触发策略 | 事件口径决定归因范围 |
| 特征名 / 特征ID | 特征配置页 | 条件为什么成立 | 特征表达式需懂口径 |
| 策略名 / 策略ID | 策略配置页 | 策略逻辑、版本、结果 | 不要只看策略名 |
| 用户ID | 事件查询 | 用户是否命中策略 | 需事件和时间窗口 |
| 时间范围 | 事件查询 | 查命中和波动 | 时间窗过宽成本高 |

## 4. 页面 / 模块结构

| 页面模块 | 核心功能 | 关键字段 | 常用场景 | 优先级 |
|---|---|---|---|---|
| 事件管理 | 事件定义、字段、触发入口 | event_id, event_name, event_fields | 策略入口理解 | P1 |
| 特征配置 | 特征表达式和加工逻辑 | feature_name, feature_expression | 策略条件解释 | P0 |
| 策略配置 v2pro | 创建/查看策略条件和结果 | policy_name, policy_condition, policy_result | 策略归因、误伤 | P0 |
| 策略树 | 策略绑定、优先级、上线保护 | policy_priority, is_protected | 线上生效和从重逻辑 | P0 |
| 事件查询 / 归因 | 查用户/事件策略命中和特征值 | hit_policy, feature_value | 策略误伤和归因 | P0 |
| 策略熔断 | 防误伤熔断 | fuse_config | 大规模误伤控制 | P1 |
| 策略报警 | 命中量波动报警 | alert_rule | 线上稳定性 | P1 |

## 5. 核心字段字典

| 字段名 | 页面展示名 | 含义 | 风控解释 | 适用场景 | 可信度/注意事项 |
|---|---|---|---|---|---|
| event_id | 事件ID | 策略触发入口 | 定义策略适用的业务动作 | 全场景策略归因 | 事件口径需确认 |
| event_name | 事件名 | 事件描述 | 帮助理解入口 | 策略归因 | 需与业务动作对齐 |
| feature_name | 特征名 | 策略使用的特征 | 解释命中原因 | 策略误伤、归因 | 名称不等于口径 |
| feature_expression | 特征表达式 | MVEL 等表达式 | 判断条件逻辑 | 策略归因 | 需谨慎解释 |
| feature_value | 特征值 | 命中时特征取值 | 判断条件是否成立 | 策略误伤 | 数据口径需确认 |
| policy_name | 策略名称 | 策略描述名 | 定位策略用途 | 全场景 | 具体策略名不是本质特征 |
| policy_condition | 策略条件 | 布尔表达式 | 命中逻辑 | 策略归因 | 需结合 feature_value |
| policy_result | 策略结果 | 命中后动作 | 推审/处置/标记/业务返回 | 治理动作 | 不是自动最终结论 |
| policy_version | 策略版本 | 版本号 | 追踪变更 | 误伤复盘 | 需看生效时间 |
| policy_status | 策略状态 | 上线/实验/下线 | 是否生效 | 策略归因 | 状态和时间需对齐 |
| policy_priority | 优先级 | 多策略从重顺序 | 决策顺序 | 策略误伤 | 需看策略树 |
| is_protected | 是否保护 | 保护策略 | 高价值账号保护 | 误伤控制 | 需确认业务口径 |
| hit_policy | 命中策略 | 用户命中的策略 | 支持策略归因 | 全场景 | 命中不等于最终定性 |
| strategy_detail | 策略详情 | 策略命中明细 | 归因上下文 | 策略误伤 | 与 RAP 摘要字段区分 |

## 6. 通用适用场景

- ATO / 账号安全：适用。查账号安全相关事件和策略命中，ATO 是典型用例之一。
- 群控 / 号商：适用。查群控策略、设备/账号团伙策略命中。
- 协议上号：适用。查协议、前后端链路、登录异常相关策略。
- 反爬 / 资产抓取：适用。查反爬策略、接口防护策略、命中量波动。
- 内容风险：适用。查内容审核、推审、处置策略。
- 假量 / 裂变：适用。查活动、奖励、增长风控策略。
- 社交骚扰：适用。查社交封禁、私信/评论风控策略。
- 策略误伤 / 策略归因：强适用。核心平台。

## 8. 典型查询路径

### 8.1 策略归因查询

- 输入：user_id + event_id/event_name + 时间窗口
- 查询模块：事件查询 / 归因
- 关键字段：hit_policy, feature_value, policy_result, timestamp
- 输出结论：用户是否命中策略、命中特征值、策略结果是什么
- 下一步平台：档案中心核验事实；用户登录统一日志查原始操作；设备攻防查设备反证

### 8.2 策略误伤复盘

- 输入：策略名 / 策略ID + 误伤样本 + 时间窗口
- 查询模块：策略配置 → 策略树 → 事件查询 → 熔断/报警
- 关键字段：policy_condition, feature_expression, policy_version, policy_status, is_protected
- 输出结论：策略逻辑是否过宽、版本是否变更、是否需熔断/灰度
- 下一步平台：DataAgent/Hive 批量评估；档案中心抽查样本事实

### 8.3 策略上线 / 调试

- 输入：事件、特征、策略条件、结果
- 查询模块：事件管理 → 特征配置 → 策略配置 → 策略树
- 关键字段：event_id, feature_name, policy_condition, policy_result, policy_priority
- 输出结论：策略配置是否完整、上线链路是否清楚
- 下一步平台：策略报警 / 熔断；DataAgent/Hive 做离线评估

## 9. Agent 路由规则

- 问题包含“为什么命中 / 哪条策略 / 特征值 / 策略条件 / 熔断 / 报警 / 误伤归因”时，优先查天狮。
- 如果用户只问事实是否存在，不应先查天狮，应先查档案中心、用户登录统一日志或设备攻防。
- 策略命中只能作为证据之一，不能替代事实链路。

## 10. Agent 解释规则

- hit_policy 支持“策略命中过”，不等于最终风险成立。
- policy_name 不能作为长期本质特征，需解释为策略类型或风险信号。
- feature_value 必须结合 feature_expression 和 policy_condition 解读。
- policy_result 是策略动作，不等于 Agent 应建议执行同样动作。
- 误伤复盘必须看 policy_version、policy_status、生效时间和保护策略。
