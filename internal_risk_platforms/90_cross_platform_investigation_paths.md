# 跨平台风控研判链路

## 1. 使用原则

- 先明确问题类型，再选第一站平台。
- 页面工具查事实，天狮查策略归因，DataAgent / Hive 查离线聚合。
- 单个平台结果不直接给最终结论；必须保留反证和下一步。
- ATO 是账号安全典型用例之一，不应把平台链路写成 ATO 专用。

## 2. 账号异常 / ATO 研判链路

```text
输入：user_id + 异常时间 + 用户自述/操作线索
→ 档案中心：查用户状态、APP端高危操作、审核日志、同设备登录
→ 用户登录统一日志：查全端登录、OAuth/扫码、token/session、高危接口 action
→ 设备攻防基建平台：查新设备、硬件可信、风险标签、安装 APP、设备图谱
→ 用户行为细查平台：查前端行为链路是否与后端操作一致
→ 天狮策略引擎：查账号安全策略命中、特征值、策略结果
→ 输出结论：是否支持账号异常 / 账号接管嫌疑；ATO 只作为典型结论之一
```

关键反证：
- 用户历史设备和地区一致。
- 高危操作 action=deny。
- 前端行为链路完整且符合本人习惯。
- 策略未命中不等于无风险，但会降低结论强度。

## 3. 群控 / 号商研判链路

```text
输入：user_id / device_id / phone_number / 可疑账号列表
→ 设备攻防基建平台：查设备可信、关联图谱、封禁比例、模拟器/刷机/多开线索
→ 档案中心：查同设备注册/登录账号、注册时间、风控状态
→ 风险运营中心：查关联账号滚雪球、同手机号/同IP/社交关系、案例留存
→ 用户行为细查平台：查行为同步、模板化、设备切换
→ 天狮策略引擎：查群控/号商相关策略命中
→ 输出结论：是否存在统一调度、设备团组、账号扩量、收益或行为聚集
```

关键反证：
- 合法矩阵、MCN、商家代运营、内部测试可解释相似性。
- 设备聚集本身不是群控，必须看统一调度和行为目标。

## 4. 协议上号研判链路

```text
输入：user_id / request_id / trace_id / 时间窗口 / 后端异常操作线索
→ 用户登录统一日志：查后端登录、业务鉴权、高危接口、method、action
→ 用户行为细查平台：查前端是否有对应页面/点击/行为链路
→ 设备攻防基建平台：查设备上报异常、SDK版本、APK风险、硬件可信
→ 档案中心：查用户状态、APP端操作和同设备关联
→ 天狮策略引擎：查协议/登录异常/账号安全策略命中
→ 输出结论：是否支持后端操作缺少前端行为的协议上号嫌疑
```

关键反证：
- 埋点缺失、版本覆盖不足、前端日志延迟。
- 合法自动化、授权工具、业务服务调用。
- 破解包或群控可能与协议行为混合。

## 5. 假量 / 裂变研判链路

```text
输入：activity_id / campaign_id / user_list / 时间窗口
→ 用户行为细查平台：查拉新后前端行为、停留、消费、互动
→ 风险运营中心：查涨粉趋势、社交数据、关联账号、举报/案例
→ 档案中心：查注册时间、风控状态、同设备注册/登录
→ 设备攻防基建平台：查设备重置、新设备、模拟器、关联图谱
→ DataAgent / Hive：批量聚合留存、转化、奖励、提现、邀请链路
→ 天狮策略引擎：查活动风控策略命中和策略结果
→ 输出结论：是否存在假量、裂变套利、渠道套利或奖励套利
```

关键反证：
- 活动自然爆发、渠道结构变化、真实低质用户。
- 低留存不等于作弊，必须看奖励闭环和组织化证据。

## 6. 内容风险研判链路

```text
输入：photo_id / liveStreamId / author_id / comment_id
→ 档案中心：查视频/直播/评论详情、视频 meta、审核日志、举报
→ 风险运营中心：查评论词云、举报分布、用户画像、关联账号
→ 用户行为细查平台：查发布/编辑/互动前端行为链路
→ 设备攻防基建平台：查发布设备是否异常、是否关联风险账号
→ 天狮策略引擎：查内容策略命中、推审/处置策略
→ 输出结论：内容风险事实、账号/设备关联、是否存在批量生产或导流
```

关键反证：
- 正常创作、合法营销、二创/转载权限、审核误判。
- 单个举报或单条评论不能直接定性。

## 7. 策略误伤归因链路

```text
输入：user_id / content_id / policy_name / event_id / 处罚时间
→ 天狮策略引擎：查事件、策略、特征值、策略结果、版本、优先级
→ 档案中心：查处罚事实、审核日志、用户/内容状态
→ 风险运营中心：查解封详情、历史判罚、关联风险
→ 用户登录统一日志 / 用户行为细查平台：查原始行为是否支持策略命中
→ DataAgent / Hive：批量评估命中量、误伤率、后验质量
→ 输出结论：策略命中是否合理、是否需降级、熔断、灰度或回滚
```

关键反证：
- 策略命中不等于风险成立。
- 用户事实和行为链路不支持策略条件时，应进入误伤复盘。
- 高风险处置动作必须人工确认。
