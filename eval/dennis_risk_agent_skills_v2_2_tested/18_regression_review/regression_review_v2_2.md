# 回归复核：测试结果是否符合预期 v2.2

## 1. 预期

基于 v2.1 Focused Deep 的定位，预期应满足：

1. 核心主战场：账号安全、反爬、活动反作弊、群控/协议，应大多通过；
2. 黑产本质类问题：应能输出作恶方、资源、链路、收益、治理断点；
3. 材料类问题：应能复现“业务情况 → 核心思考 → 策略打法 → 核心进展 + 一句话总结 → 做得好/可提升 → 下一步”；
4. 不应过拟合外部案例和历史材料；
5. 非核心或缺真实字段的方向允许边界分，但要明确缺口。

## 2. 实际

- 通过数：48 / 50
- 边界/不通过：2 / 50
- 平均分：84.9

## 3. 符合预期的部分

- 账号安全、反爬、活动反作弊核心案例大多通过；
- 群控、协议相关案例评分较高；
- 业务领域大图、年度述职、策略树类材料交付能被明确验收；
- 外部案例聚焦后，没有明显干扰 Skill 路由；
- 多数测试都能要求反证、灰度和指标。

## 4. 不符合或低于预期的部分

- 导流截流仍偏轻，需要从“内容治理”升级成“目标获取-触达-承接-变现”的完整链路；
- 真人众包仍不够深，需要更多任务平台和低质质量评估；
- 破解包需要补工件、短链、runtime 证据；
- 工具规划缺真实字段，无法完全落地；
- 部分材料类输出仍需要真实指标口径，不能仅用模板。

## 5. 回归判断

测试结果符合我们对 v2.1 的真实预期：  
**它是一个明显增强的专家深度起点，大部分核心主战场可用，但仍需继续靠真实 case、反例和字段口径推进。**

不应把当前版本评成 90+。更合理评分仍是 **84-86 分区间**。
