# 50 个历史材料测试案例交叉验证报告 v2.2

## 1. 测试目标

用 50 个从历史记忆、年度述职、业务领域大图、成功策略图和高频对话中抽象出的测试案例，验证 v2.1 Focused Deep 是否真的具备“专家级内容深度”，而不是只像风格和目录。

## 2. 测试集构成

| 领域 | 数量 |
|---|---:|
| 账号安全 | 10 |
| 反爬 | 12 |
| 流量反作弊 | 3 |
| 活动反作弊 | 10 |
| 黑灰产基建 | 8 |
| AI Agent | 3 |
| 表达交付 | 3 |
| 综合混合攻击 | 1 |

总计：50 个。

## 3. 评分口径

满分 100，按照：

| 维度 | 权重 |
|---|---:|
| 专家级内容深度 | 45 |
| 证据与治理可执行性 | 20 |
| 材料级交付能力 | 15 |
| 边界与防过拟合 | 10 |
| Codex 可执行性 | 10 |

80 分以上为通过，72-79 为边界，72 以下为不通过。

## 4. 总体结果

- 平均分：84.9
- 最高分：89
- 最低分：77
- 通过数：48
- 边界/不通过数：2

## 6. 结论

v2.1 对账号安全、反爬、活动反作弊、群控/协议类问题的覆盖已明显增强，能通过大多数高频测试。  
但在以下方向仍有短板：

1. 导流截流：需要更多站外承接、私信触达、矩阵治理细节；
2. 真人众包：需要更多任务平台、收益链和低质质量指标；
3. 破解包：需要更多样本级证据、逆向短链和工件级判断；
4. 工具规划：需要真实表名、字段、权限和审计边界；
5. 材料类输出：需要真实指标口径确认，避免跨年份误用。

## 7. 是否符合预期

整体符合“v2.1 是深度可用起点，不是满分版本”的预期。  
它比 v1.x 的框架包明显更接近 Dennis 的真实工作方式，但还不能声称完全蒸馏完成。
