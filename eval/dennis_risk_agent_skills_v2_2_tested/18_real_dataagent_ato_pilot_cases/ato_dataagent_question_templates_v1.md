# ATO Data Agent Question Templates v1

## 0. 使用边界

本文件用于 v2.4 Data Agent-only 真实只读试点。Data Agent 只负责取数、找表、SQL 生成、离线数据摘要和覆盖范围说明；Dennis Agent 负责证据解释、结论等级、边界降级和人工复核闭环。

禁止把用户申诉、人工备注或 Data Agent 的结论性文字直接当作最终事实。禁止输出处罚、冻结、扣除、封禁、自动解封或策略上线建议。

## 1. 通用模板

```text

目标接口 / 业务动作：
登录行为、登录方式变化、设备/IP/地区变化、token/session 变化、发布作品行为、账号资料变更、换绑/改密/找回、策略命中/风险画像/回扫记录。

已知背景：
{user_claim_summary}

人工备注：
{manual_note}

取数目标：
验证该账号在时间窗口内是否存在支持“盗号 / 登录态被接管 / 钓鱼 / 扫码 / 密码泄露 / 短信泄露 / OAuth token 异常”的离线数据证据。

请尽量输出：
1. 时间窗口内是否存在登录行为，登录时间、登录方式、设备、IP/地区是否异常。
2. 是否出现新设备、异地、非常用环境、短时间多环境切换。
3. 是否出现密码登录、验证码登录、微信登录、扫码/OAuth授权等登录方式变化。
4. 是否存在 token/session 被踢、复用、异常切换或多端冲突线索。
5. 登录后是否发生发布作品、资料变更、换绑、改密、找回等敏感动作。
6. 敏感动作与异常登录之间是否存在时间链路。
7. 是否存在盗号、钓鱼、扫码、短信泄露、密码泄露、OAuth 风险画像或策略命中。
8. 是否存在回扫记录或处置链路。
9. 哪些是数据发现，哪些只是模型推测。
10. 哪些关键证据缺失，例如实时登录链路、实时设备指纹、实时策略引擎、外部钓鱼来源明细。
11. 当前最多支持什么 provider_conclusion_hint。

注意：
这里只做只读取证分析，不需要给处罚、冻结、扣除、封禁或策略上线建议。
不要因为用户申诉就直接判断盗号。
不要把人工备注当作数据事实。
如果缺权限、无结果、只生成 SQL 或查询失败，请明确说明。
不要编造真实表名、字段名、接口路径或 SQL 执行结果。
```
