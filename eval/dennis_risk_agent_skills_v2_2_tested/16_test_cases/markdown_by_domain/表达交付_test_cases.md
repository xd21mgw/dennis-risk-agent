# 表达交付 测试案例


## AG-004｜领域大图

**问题：** 基于业务领域大图格式，生成某业务风控全景大图应包含什么？

**黑产/风险本质：** 领域大图是治理取舍和指标体系，不是简单功能列表。

**期望触发 Skill：**
- business_domain_map_skill
- material_delivery_skill

**必须覆盖：**
- 领域/子领域/治理态度/策略打法/观测指标/轻重边界/依赖能力

**不能出现：**
- 所有方向都重点建设
- 没有指标

**交付类型：** material  
**难度：** medium


## AG-005｜策略树

**问题：** 给一个新风险，什么时候用树状策略图，什么时候用一页纸汇报图？

**黑产/风险本质：** 策略树适合策略同学工作和证据推理，一页纸适合管理层同步。

**期望触发 Skill：**
- diagram_generation_skill
- material_delivery_skill

**必须覆盖：**
- 适用场景区分
- 中心问题
- 一级风险
- 证据/处置/指标
- 管理层简化

**不能出现：**
- 所有图都做成树状
- 只追求好看

**交付类型：** risk_answer  
**难度：** medium


## AG-006｜面试项目讲法

**问题：** 把反爬 6+1、账号安全、活动反作弊三个项目包装成高阶面试表达怎么讲？

**黑产/风险本质：** 面试表达要体现体系化、组织协同、业务价值和认知迭代。

**期望触发 Skill：**
- interview_storytelling_skill
- executive_summary_skill
- anti_crawler_expert_skill
- account_security_expert_skill
- activity_anti_cheating_expert_skill

**必须覆盖：**
- 背景/问题/动作/结果/沉淀
- 指标
- 负责人视角
- 追问准备

**不能出现：**
- 只讲技术细节
- 没有业务价值

**交付类型：** material  
**难度：** medium
