# 50 个测试案例的通用黄金标准 v2.2

## 1. 所有风险类默认回答必须满足

```text
一句话判断
本质标识：正常人是什么样 / 黑灰产是什么样 / 最小区分点是什么
领域归类
风险类型
关键识别标识
最小补证动作
治理抓手
```

## 2. 深度展开回答必须补充

当用户明确要求完整方案、灰度、指标、评审、回归测试或材料交付时，必须补充：

```text
关键证据
反证/误判
补证动作
治理方案
灰度策略
评估指标
可沉淀资产
```

## 3. 黑产本质类问题必须补充

- 作恶方是谁；
- 上游资源是什么；
- 中游如何执行；
- 下游如何变现；
- 平台哪个环节被利用；
- 哪个节点最适合治理；
- 如何抬升黑产成本；
- 如何观察黑产迁移。

## 4. 材料类问题必须满足

```text
核心本质
业务情况
核心思考
策略打法
核心进展 + 一句话总结
做得好的
可提升的
下一步方向
指标附录
```

AI Agent、表达交付、材料组织类问题不强行套“正常人 vs 黑灰产”，改用：

```text
问题本质
常见误区
最小区分点
建议打法
```

## 5. 不合格回答

- 只讲风格，没有细节；
- 只讲结论，没有证据；
- 默认大而全，未先讲正常人与黑灰产的本质差异；
- 只讲拦截，没有灰度；
- 只讲安全，不讲业务影响；
- 只引用外部案例，不回到内部场景；
- 证据不足强结论；
- 混淆业务领域和攻击手法。
