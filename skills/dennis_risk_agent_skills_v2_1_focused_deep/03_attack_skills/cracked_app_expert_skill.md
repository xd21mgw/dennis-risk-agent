# Cracked App Expert Skill：破解包治理 Skill v2.1

## 认知

破解包是被改造的客户端，可能绕过采集、签名、验证、展示限制，或注入自动化/插件能力。破解包不是协议，但可能制造“像协议”的端行为缺失。

## 分型

- 去 SDK/去采集破解；
- 签名/参数绕过破解；
- 功能解锁破解；
- 注入插件破解；
- 去广告/改展示破解；
- 自动化辅助破解。

## 证据

- 包签名异常；
- 版本/渠道异常；
- SDK 日志缺失；
- 关键 so/dex/assets 异常；
- 安全模块被替换；
- 同包名不同签名；
- 行为请求正常但端采集缺失；
- 外部分发渠道样本。

## 治理

包完整性校验、签名校验、强制升级、关键接口上下文绑定、风险设备限制、外部分发监测、逆向样本库、插件证据回流。

## 指标

破解包发生量、样本数、覆盖版本、风险接口占比、处置后迁移、误伤、业务影响。
