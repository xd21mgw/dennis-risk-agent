# Real User Crowdsourcing Skill：真人众包风险 Skill v2.1

## 认知

真人众包是“行为真实，但目标任务化”。它和群控/协议不同，不一定有设备或接口异常，核心在组织化任务和收益链路。

## 证据

- 行为真实但目标高度一致；
- 时间窗口集中；
- 任务平台教程/话术；
- 低留存、低钱效；
- 收益领取/提现聚集；
- 多地真人离散但任务路径一致；
- 站外组织痕迹。

## 边界

- 不是正常自然用户；
- 不等于群控；
- 不等于协议；
- 不能因“真人”就不治理。

## 治理

降低任务收益、延迟结算、后验质量评估、任务随机化、关键动作验证、业务钱效监控、外部情报回流。

## 指标

低质占比、钱效、留存、付费、提现聚集、任务完成异常、客诉。
