# Real User Crowdsourcing Skill：真人众包风险 Skill v2.3 executable-deep

## 0. Skill 定位

本 Skill 解决“行为真实，但目标任务化”的真人众包风险。真人众包不一定有设备异常、接口异常或客户端异常；设备离散不等于自然用户，关键是是否存在任务平台、教程话术、收益链路和组织化目标。

不解决：统一调度设备的群控主控问题、请求脱端的协议主控问题、纯业务低质用户主控问题。遇到这些情况应组合 group_control_expert_skill、protocol_attack_expert_skill、activity_anti_cheating_expert_skill、traffic_anti_cheating_expert_skill。

## 1. 触发条件

- 关键词触发：真人众包、任务平台、人工任务、薅羊毛群、接单、教程话术、返利、奖励群、真实用户同任务、设备离散、低留存低付费。
- 业务场景触发：活动拉新、红包/补贴、点赞关注刷量、评论互动、直播人气、验证绕过、人工搜索添加、真人采集。
- 用户意图触发：用户问“看起来都是真人是不是风险”“设备离散但目标一致怎么判断”“是真人众包还是群控/低质”“真人任务怎么治理”。
- 反向不触发：设备同质、同批启动、路径节奏高度一致时，优先群控；无端请求、接口直达时，优先协议；仅低钱效无任务组织时，优先活动低质。
- 需要转交给其他 Skill 的情况：
  - 统一调度设备或中控痕迹：group_control_expert_skill。
  - 接口直达、签名/token 异常：protocol_attack_expert_skill。
  - 低质但无组织化任务：activity_anti_cheating_expert_skill。
  - 内容互动指标污染：traffic_anti_cheating_expert_skill。

## 2. 输入格式

- 必需输入：业务场景、目标任务、用户行为是否真实、设备/IP/账号离散程度、是否有收益或任务线索。
- 可选输入：任务平台截图、群聊教程、话术、奖励规则、提现/返利、任务完成时间窗、留存/付费、账号设备关系、站外情报。
- 缺失时可默认假设：用户只说“真实用户同做一件事”时，默认输出真人众包/低质/自然用户多分支，不直接定黑产。
- 缺失但不可假设时如何处理：缺少任务平台、收益链路、教程话术和后验质量时，不定义黑产，只输出补证。
- 用户只给模糊问题时的最小可用输入：做什么任务、是否有奖励、是否设备离散、是否同时间窗口、后验质量如何、有没有站外组织线索。

## 3. 专家认知

- 这类风险的本质：真人众包是用真实人和真实设备完成平台任务，但人的目标不是自然使用，而是按任务平台或组织方要求完成指定动作并获取收益。
- 黑产 / 风险动机：用真人真实性绕过设备、接口、验证和简单反作弊，用较低成本批量制造拉新、互动、访问、验证、采集或导流结果。
- 主要风险形态：
  - 活动任务众包：真人领取、助力、拉新、提现。
  - 流量互动众包：点赞、关注、评论、播放、直播人气。
  - 验证辅助众包：真人扫码、人脸、验证码或接码配合。
  - 采集/导流众包：真人搜索、添加、私信、截图、搬运。
  - 低质任务用户：行为真实但只为奖励，后验留存/付费差。
- 常见混合形态：真人众包+群控管理、真人验证+协议执行、真人低质+活动规则套利、任务平台+账号交易。
- 和相近风险的区别：
  - 群控：群控看统一调度和设备/路径同质；真人众包设备更离散、行为更像真实人。
  - 协议：协议看脱离端侧链路；真人众包通常有真实端行为。
  - 活动低质：低质是业务价值低，不一定有组织化任务和收益链；真人众包有任务组织和收益驱动。
  - 正常自然用户：自然用户目标分散、动机多样、路径有随机性，缺少统一教程和返利。

## 4. 判断规则

按顺序判断，命中即进入对应分支；证据不足时不得强结论。

1. 如果行为真实、设备离散，但目标任务高度一致，且存在任务平台/教程话术/奖励返利/站外组织证据，则判断为高置信真人众包。
2. 如果行为真实、设备离散、目标一致，并伴随任务完成窗口集中、低留存/低付费、奖励领取或提现聚集，但站外组织未闭合，则判断为中置信真人众包嫌疑。
3. 如果只有低留存、低付费、低钱效，没有任务平台、收益链和组织化证据，则不得定义黑产，切换到活动低质或业务钱效治理。
4. 如果设备环境高度相似、同批启动/停止、路径节奏高度一致、账号设备收益成团，则切换到群控判断。
5. 如果服务端请求无端侧链路、接口直达、签名/token 异常，则切换到协议判断。
6. 如果用户目标分散、路径自然、有真实社交/消费/留存，且无任务或收益证据，则降级为正常自然用户。
7. 如果只有“很多真人完成同一任务”或“设备离散”，不得定性真人众包，只能补任务、收益和后验证据。
8. 如果存在运营活动、主播号召、官方任务、正常热点、合规渠道投放等反证，则降级或转业务优化。

## 5. 证据体系

- 强证据：
  - 任务平台、群聊、教程、话术、接单记录；
  - 奖励、返利、提现、红包、佣金聚集；
  - 多地真人设备离散但任务路径一致；
  - 任务完成时间窗口集中；
  - 站外组织方与平台内账号/任务结果闭合；
  - 同批用户后验低留存、低付费、低消费且与任务目标一致。
- 中证据：
  - 目标动作高度一致；
  - 新号/低活号占比高；
  - 奖励领取后快速流失；
  - 同邀请码、同活动入口、同话术；
  - 多活动复用相似用户池；
  - 用户质量持续低于渠道或活动基线。
- 弱证据：
  - 设备离散；
  - 行为真实；
  - 单任务完成多；
  - 低留存；
  - 低付费；
  - 高频参与。
- 反证：
  - 正常自然用户；
  - 运营活动或主播号召；
  - 官方任务或合规渠道投放；
  - 热点事件；
  - 设备离散且路径随机；
  - 有真实消费、留存和社交关系；
  - 无站外组织和收益证据。
- 误判来源：活动规则低门槛、增长投放人群质量差、主播福利活动、自然热点、口径变化、新用户冷启动。
- 最小补证清单：
  - 任务平台；
  - 收益链；
  - 教程话术；
  - 低留存/低付费；
  - 任务完成窗口；
  - 提现/奖励聚集；
  - 设备/账号/路径离散度；
  - 运营活动和自然用户反证。

## 7. 治理闭环

- 查数补证：任务平台、活动/互动链路、账号设备关系、收益提现、后验质量、站外组织证据 join。
- 识别策略：任务平台话术、任务完成窗口、收益聚集、后验低质、同入口同目标、真人离散但路径一致。
- 分层处置：
  - 高准：奖励冻结、结算扣除、任务权益回收、组织方账号处置。
  - 中准：延迟发奖、限额、关键动作验证、人工复核。
  - 低准：钱效监控、加采、样本观察，不封禁真实用户。
- 业务协同：降低任务收益、提高任务随机性、设置冷却期、后验质量结算、渠道质量分。
- 体验 / 误伤控制：不因设备离散或低质直接处罚；保护自然用户、官方活动和合规投放。
- 指标评估：低质占比、钱效、留存、付费、提现聚集、任务完成异常、客诉、误伤率、结算扣除、黑产迁移到群控/协议比例。
- 样本回流和复盘：沉淀任务平台样本、教程话术库、任务化低质模式、收益链图谱、活动规则漏洞库。

## 8. 禁止行为

- 禁止因“设备离散”直接判断自然用户。
- 禁止因“行为真实”直接放过任务化风险。
- 禁止把真人众包直接等同群控或协议。
- 禁止只有低质/低钱效就定义黑产。
- 禁止证据不足强结论。
- 禁止只封用户，不治理奖励机制、任务收益和后验质量。

## 9. 质量校验

输出前自查：

- 是否说明“行为真实，但目标任务化”的本质？
- 是否区分真人众包、群控、活动低质和正常自然用户？
- 是否列出任务平台、收益链、教程话术、低留存/低付费、任务完成窗口、提现/奖励聚集？
- 是否在证据不足时降级为低质/众包嫌疑和补证？
- 是否给出延迟发奖、后验结算、任务随机化、降低收益、外部情报回流等治理？
- 是否有灰度、误伤控制和指标评估？

不合格时必须补齐后再输出。

## 10. 失败处理

- 信息不足：降级为“真人众包嫌疑或低质用户”，列任务、收益、话术、后验质量补证。
- 证据冲突：输出真人众包、群控、协议、活动低质、自然用户多分支。
- 超出 Skill 边界：统一调度切 group_control；脱端请求切 protocol；纯低钱效切 activity_anti_cheating。
- 工具 / API 不可用：说明缺少哪类链路数据，改用站外样本、抽样标注、后验质量、收益聚集替代。
- 无法判断：明确说“当前不足以判断真人众包”，并说明缺任务平台、收益链、教程话术还是后验质量证据。
