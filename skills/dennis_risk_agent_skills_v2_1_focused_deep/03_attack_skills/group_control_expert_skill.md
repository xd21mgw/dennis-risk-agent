# Group Control Expert Skill：群控专项专家 Skill v2.1

## 1. 一句话认知

群控的本质不是“很多设备一起动”，而是黑产通过中控系统、云手机、真机农场、模拟器、改机、插件或脚本，批量调度账号/设备完成特定业务目标。

判断群控的关键不是“量大”，而是“是否存在统一调度”。

## 2. 主要形态

| 形态 | 特征 | 常见场景 |
|---|---|---|
| 云手机群控 | 云端环境批量运行，环境相似 | 活动、导流、刷量 |
| 真机农场 | 大量真实设备托管，脚本/中控调度 | 高价值活动、反爬 |
| 模拟器群控 | 低成本环境，指纹相似 | 注册、小号、激励 |
| 改机群控 | 修改设备参数，复用设备资源 | 注册、活动、账号 |
| 插件辅助群控 | 辅助功能/外挂自动操作 | 抢红包、私信、爬取 |
| 真人+群控 | 真人做关键验证，群控批量执行 | 登录、验证、提现 |
| 账号矩阵群控 | 多账号在少量环境中被调度 | 刷量、导流、养号 |

## 3. 为什么黑产用群控

- 比纯协议更像真实客户端；
- 比真人成本低；
- 可绕过简单频控；
- 可批量完成任务和收益变现；
- 可跨活动、反爬、账号、导流多场景复用。

## 4. 与相近风险边界

| 对比对象 | 区分点 |
|---|---|
| 协议 | 协议缺端行为，群控通常有端行为但调度异常 |
| 真人众包 | 真人众包行为更离散，群控节奏/路径/设备更同质 |
| 破解包 | 破解包是客户端改造，群控是批量调度；两者可混合 |
| 合法矩阵 | 合法矩阵有授权和业务合理性，群控以规避平台规则获利 |
| 自然热点 | 自然热点有随机性，群控有同批、同路径、同收益目标 |

## 5. 证据体系

### 强证据
- 同批启动/停止；
- 设备环境高度相似；
- 多账号共设备或设备轮换；
- 页面路径、点击节奏、任务顺序高度一致；
- 账号-设备-IP-收益形成团组；
- 收益集中流向少量主体；
- 发现插件、中控、自动化痕迹。

### 中证据
- 同 IP 段集中；
- 账号画像低质；
- 任务完成时间窗口集中；
- 同业务动作重复。

### 弱证据
- 高频访问；
- 设备聚集；
- 账号聚集；
- 单接口异常。

### 反证
- 合法运营矩阵；
- 活动自然传播；
- 埋点缺失；
- 协议攻击；
- 真人众包；
- 公司测试/蓝军。

## 6. 查数动作

- 查设备指纹、设备环境相似度、模拟器/云手机/改机特征；
- 查账号注册、登录、活跃、任务、提现链路；
- 查页面路径、点击节奏、停留、跳转、任务顺序；
- 查 IP、代理、地理、邀请、支付、提现、收货关系；
- 查收益链路：券、红包、佣金、提现、刷量收益；
- 查是否存在合法运营授权；
- 查是否混合协议、破解包或真人众包。

## 7. 治理方案

### 高准
账号封禁、设备处置、收益冻结、提现拦截、任务权益回收。

### 中准
限权、限额、延迟发奖、强验证、设备验证、人工审核。

### 低准
观察、降权、加采、进入监控池、样本回流。

### 成本抬升
强制登录、无感验证、强制升级、任务随机化、收益延迟、结算扣除。

### 业务联动
降低单用户获利上限、引入冷却期、渠道/活动规则改造、异常收益回收。

## 8. 指标

群控发生量、漏过量、准确率、召回率、误伤率、资损变化、客诉变化、黑产成本、迁移路径、策略稳定性、业务钱效。

## 9. 能力建设

看清 → 打准 → 治理闭环 → 通能复用。

- 看清：建样本库、关系图、业务路径图；
- 打准：设备团组、行为节奏、收益聚集策略；
- 闭环：账号/设备/收益/任务/提现联动；
- 复用：活动、反爬、账号、导流、支付跨场景标签和策略包。
