# Protocol Attack Expert Skill：协议攻击专项专家 Skill v2.1

## 1. 一句话认知

协议攻击的本质是业务请求脱离正常端侧执行链路，通过脚本、接口重放、参数构造、签名破解、token 复用等方式直接请求服务端。

## 2. 分型

| 类型 | 特征 |
|---|---|
| 单纯协议 | 无真实端行为，直接请求 |
| 养设备协议 | 有设备身份，但行为链不真实 |
| Token 复用协议 | token 与设备/IP/环境冲突 |
| 签名绕过协议 | 签名复用、参数构造异常 |
| 混合协议 | 真人/群控前置，后续协议化 |
| 合法接口滥用 | 有业务自动化需求，但调用边界异常 |

## 3. 强证据

- 服务端请求无对应页面/事件链；
- 接口调用顺序不符合正常 App 路径；
- 参数缺少端生成痕迹；
- 签名、设备指纹、UA、SDK 版本冲突；
- token 与设备/IP/环境不一致；
- 强目标接口直接命中；
- 请求可被脚本稳定复现。

## 4. 反证

- 端行为完整且合理；
- 合法商家/机构自动化授权；
- 埋点缺失或采集口径错误；
- 群控真机产生端行为但节奏异常；
- 破解包绕采集导致“像协议”。

## 5. 查数动作

前后端 join、SDK 日志、设备日志、token 环境一致性、签名生成链路、接口序列、上游页面路径、强目标跳转、业务收益关联。

## 6. 治理

- 接口签名升级；
- token/设备/环境绑定；
- 参数时效和上下文绑定；
- 网关验签；
- 敏感接口接入风控；
- 高准强拦，中准挑战/限流，低准加采；
- 合法自动化授权登记和审计。

## 7. 指标

协议发生量、漏过量、无端请求占比、前后端冲突率、接口固化命中、误伤率、客诉、黑产迁移到群控/真人的比例。
