# 外部案例：账号安全聚焦

## 使用边界

只用于补充账号安全、撞库、ATO、新账号欺诈、验证和风控决策认知，不替代内部证据。

## 可吸收原则

1. Credential stuffing 是泄漏凭证批量测试，不等于普通暴力破解。
2. ATO 治理要覆盖登录、下游扩散、风险 token、找回。
3. 新账号欺诈要看注册前风险信号：设备、行为、身份、网络情报。
4. Step-up/MFA 应按风险分层触发，避免体验过损。
