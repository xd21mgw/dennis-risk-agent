# 外部案例：流量反作弊聚焦

## 使用边界

只用于增强刷量、点击欺诈、内容抓取、库存占用、虚假流量和指标可信相关认知。

## 可吸收原则

1. 流量风险要同时看外部价格、内部漏出、质量指标和业务口径稳定性。
2. 点击欺诈、content scraping、inventory hoarding 都可归入广义流量反作弊视角。
3. 治理不只拦截，还包括数据矫正、SLA、业务口径稳定、柔性处置。
