# 外部案例：活动反作弊 / Promo Abuse 聚焦

## 使用边界

只用于增强促销滥用、新账号欺诈、优惠滥用、推荐欺诈等活动风险认知。

## 可吸收原则

1. Promo abuse 常与弱身份、新账号、多账号、设备聚集、异常兑换节奏相关。
2. 不能只靠强拦，要平衡转化和风控。
3. 活动风险要区分黑产、低质、真实用户套利、规则漏洞。
4. 治理要覆盖注册、领取、使用、提现/结算、后验质量。
