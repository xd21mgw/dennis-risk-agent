# 外部案例：反爬 / Bot / Scraping 聚焦

## 使用边界

只用于增强反爬、核心资产防护、Bot 管理、内容抓取、库存占用、价格情报相关认知。

## 可吸收原则

1. Bot 风险不只是 DDoS，还包括 credential stuffing、content scraping、inventory hoarding、click fraud。
2. Web scraping 对电商影响包括性能、成本、价格/库存/内容泄漏、竞品情报。
3. Scraper 可能使用 headless browser、代理、真人化行为，不能只看频率。
4. 防护要从资产、入口、行为、处置、评估闭环设计。
