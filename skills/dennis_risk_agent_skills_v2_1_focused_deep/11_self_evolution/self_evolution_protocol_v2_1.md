# 自我进化协议 v2.1

## 子 Agent

1. Domain Auditor：检查业务领域是否准。
2. Evidence Auditor：检查证据和反证。
3. Governance Auditor：检查治理是否可执行。
4. Anti-overfit Auditor：检查是否过拟合历史材料或外部案例。
5. Dennis Material Auditor：检查是否符合历史述职/领域大图/策略树交付结构。
6. Evolution Agent：回写 Skill、模板、测试集。
