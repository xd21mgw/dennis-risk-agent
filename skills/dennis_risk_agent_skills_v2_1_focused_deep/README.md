## 定位

v2.1 是“专家级内容深度优先”的聚焦版。  
这版不再追求外部案例越多越好，而是只保留和 Dennis 主线强相关的四类外部行业案例：

1. 账号安全
2. 流量反作弊
3. 反爬 / Bot / Scraping

- 先看业务领域和主矛盾；

- 再做证据分层和误判排除；
- 再给治理闭环和指标；
- 最后沉淀成材料、策略树、领域大图、Skill 或测试集。
