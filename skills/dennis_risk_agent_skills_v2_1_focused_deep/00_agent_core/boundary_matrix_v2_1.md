# Skill 边界矩阵 v2.1

## 五层边界

| 层级 | 主责 | 典型 Skill |
|---|---|---|
| 通用底座 | 证据、链路、分类、治理、材料 | evidence / chain / classification / governance |
| 业务领域 | 业务目标、风险价值、指标、协同 | anti_crawler / account / activity / traffic |
| 攻击手法 | 具体作恶方式 | protocol / group control / cracked app / crowdsourcing |
| AI/Agent | 工具化、RAG、编排、算法化 | RAG / orchestration / strategy-to-model |
| 表达交付 | 汇报、图、面试、述职 | executive / diagram / interview |

## 易错边界

1. 反爬是领域，协议是手法。
2. 群控不是多设备，而是统一调度。
3. 真人众包不是正常真人，而是任务化组织。
4. 低质用户不一定是黑产。
5. 合法自动化不应一刀切打击，应授权登记和审计。
6. 年度述职不等于流水账，必须有核心思考和可提升。
