# 专家级内容深度标准 v2.1

## 评分权重

| 维度 | 权重 |
|---|---:|
| 专家级内容深度 | 45 |
| 证据与治理可执行性 | 20 |
| 材料级交付能力 | 15 |
| 边界与防过拟合 | 10 |
| Codex 可执行性 | 10 |

## 单 Skill 合格标准

每个 Skill 必须覆盖：

1. 风险认知；
2. 风险分型；
3. 黑产/业务动机；
4. 强证据、弱证据、反证；
5. 和相近风险的边界；
6. 查数和补证动作；
7. 治理方案；
8. 灰度与误伤控制；
9. 评估指标；
10. 能力建设和沉淀方式。

少于 6 项，不合格；只有定位和输出格式，最高 50 分。
