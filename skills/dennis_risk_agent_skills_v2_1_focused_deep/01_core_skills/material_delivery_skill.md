# Material Delivery Skill：材料级交付 Skill v2.1

## 目标

把风险分析组织成 Dennis 认可的材料形态。

## 年度 / 季度复盘

业务情况 → 核心思考 → 策略打法 → 核心进展 + 一句话总结 → 做得好的 / 可提升的 → 下一步方向

年度材料的稳定写法：

- 组织定位：先说明责任边界和三大阵地，例如资金、流量、账号；
- 核心主线：用一条认知升级串联，而不是罗列项目；
- 业务情况：讲当前阶段和矛盾，例如成熟平台期、快速发展期、历史负债期；
- 核心思考：讲治理态度和取舍，例如守城战到攻城战、核心资产防护、降负债/降发生/降影响；
- 策略打法：按站内/站外、前中后链路、短中长期拆；
- 核心进展：每个项目必须有一句话总结和指标；
- 做得好的：突出认知、体系、协同、价值；
- 可提升的：讲真实短板，例如落地应用不足、BP 机制弱、业务价值存在感弱、基建滞后；
- 下一步方向：业务保障、协同提效、能力沉淀。

## 业务领域大图

领域 / 子领域 / 治理态度 / 策略打法 / 观测指标 / 轻重边界 / 依赖能力

## 策略树

中心问题 → 一级风险 → 二级手法 → 特征 / 证据 / 处置 / 指标

## 质量要求

必须有主线、指标、反思、下一步；不能变成流水账。

## 常用材料主线

- 增长反作弊：站内黑产对抗守基本盘，真人低质做厚价值，站外投放反作弊拓展防线；
- 反爬：从接口策略对抗升级到核心资产防护体系，外部价值靠投诉、报价、诉讼、蓝军验证表达；
- 账号安全：从登录拦截升级到账号生命周期治理，核心是清偿历史负债并平衡安全体验；
- 黑灰产基建：从单场景止损升级到协议、群控、小号、插件、设备等通能能力复用；
- 管理表达：从个人解决问题升级到组织能力交付，强调梯队、授权、BP 协同和可替代性。
