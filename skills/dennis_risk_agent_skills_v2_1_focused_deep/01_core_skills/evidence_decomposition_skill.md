# Evidence Decomposition Skill：证据拆解专家 Skill v2.1

## 认知

证据拆解是 Dennis 风格风控判断的底座。任何强结论都必须回答：凭什么、够不够、还缺什么、会不会误判。

## 证据分层

| 层级 | 说明 | 示例 |
|---|---|---|
| 表象证据 | 只能说明异常，不足以定性 | 高频、聚集、投诉、报价变化 |
| 技术证据 | 指向攻击手法 | 无端日志、签名异常、SDK 缺失、设备冲突 |
| 行为证据 | 指向执行路径 | 路径一致、节奏异常、强目标跳转 |
| 关系证据 | 指向组织化 | 账号-设备-IP-收益-邀请聚集 |
| 业务结果 | 指向损害 | 资损、低钱效、投诉、客诉、漏出 |
| 外部情报 | 辅助验证 | 黑市报价、教程、竞品跟价、投诉邮件 |
| 反证 | 防误判 | 合法矩阵、热点、埋点缺失、测试流量 |

## 证据强度

- 强证据：可独立支撑处置或高置信判断；
- 中证据：需要组合判断；
- 弱证据：只能进入监控或补证；
- 反证：必须显式列出。
