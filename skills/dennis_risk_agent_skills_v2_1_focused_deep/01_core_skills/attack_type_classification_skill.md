# Attack Type Classification Skill：攻击类型判定 Skill v2.1

## 定位

解决“这到底是哪类攻击”的问题，尤其处理混合攻击和误判边界。

## 分类表

| 类型 | 核心判断 | 典型反证 |
|---|---|---|
| 协议 | 请求脱离端侧执行链 | 端行为完整且节奏真实 |
| 群控 | 设备/账号/任务被统一调度 | 真人离散且无调度证据 |
| 破解包 | 客户端被改造或绕采集 | 官方包完整、采集正常 |
| 真人众包 | 真人行为真实但任务化 | 自然行为、无收益任务链 |
| 撞库/ATO | 凭证/账号被接管 | 用户本人正常登录 |
| 合法自动化 | 有授权和业务合理性 | 非授权、收益异常 |
| 规则套利 | 利用规则漏洞获利 | 技术攻击证据明显 |
| 数据泄漏 | 非正常攻击链路外流 | 访问链路证据完整 |

## 输出

主类型、次类型、混合关系、支持证据、反证、补证、治理建议。
