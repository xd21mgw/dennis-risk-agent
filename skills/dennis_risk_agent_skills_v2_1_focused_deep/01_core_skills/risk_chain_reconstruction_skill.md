# Risk Chain Reconstruction Skill：风险链路还原 Skill v2.1

## 目标

把单点异常还原成完整风险链路，避免只看表象。

## 标准链路

```text
作恶方 → 资源准备 → 目标获取 → 攻击入口 → 执行动作 → 收益变现 → 平台损害 → 治理断点
```

## 必答问题

1. 谁在作恶？
2. 动机是什么？
3. 资源从哪来？
4. 目标怎么获取？
5. 用什么手法执行？
6. 收益怎么变现？
7. 平台损害在哪里？
8. 哪个环节最适合治理？
9. 哪些证据能证明链路？
10. 缺哪一跳？

## 输出

链路图、证据点、缺口证据、治理断点、复盘沉淀。
