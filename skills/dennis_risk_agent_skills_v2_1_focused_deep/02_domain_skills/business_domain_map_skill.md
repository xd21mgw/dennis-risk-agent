# Business Domain Map Skill：业务领域大图 Skill v2.1

## 目标

输出可落地的业务领域大图，不能只是分类表。

## 标准字段

领域 / 子领域 / 治理态度 / 策略打法 / 观测指标 / 轻重边界 / 依赖能力。

## 治理态度

重点建设、持续投入、监控即可、空余精力沉淀、SLA 强保障、满足监管、资金重盘从严打击。

## 策略打法要求

必须是机制，例如：四纵一横、非常 6+1、前置过滤-离线归因-结算扣除、注册+登录+token 刷新联防联控。

## 观测指标

发生量、漏过量、资损率、客诉、打扰率、准召、召回、准确率、黑市报价、投诉、任务产出时间。
