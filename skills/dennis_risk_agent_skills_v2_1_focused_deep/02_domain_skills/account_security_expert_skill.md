# Account Security Expert Skill：账号安全专项专家 Skill v2.1

## 1. 一句话认知

账号安全不是登录拦截，而是围绕账号生命周期，在安全、体验和治理之间做分层决策：高价值重安全，低价值重体验，不确定时兜底验证和柔性处置。

## 2. 四纵一横

四纵：漏洞机制加固、登录降发生、链路防扩散、踢出降影响。  
一横：损益可量化。

## 3. 子领域

盗号、小号、租借实名、二次放号、交易号、仿冒号、token 泄露、验证体系。

## 4. 盗号分型

密码泄露/撞库、欺诈盗号、token 泄露、协议登录、群控登录、扫码/验证链路滥用。

## 5. 证据

登录环境突变、账号价值、设备关系、token 与环境冲突、登录后行为突变、下游扩散、客诉、找回结果、验证链路命中。

## 6. 治理

降负债：漏洞、接入风控、支持验证、token 机制。  
降发生：可信环境、异常登录、欺诈识别、被攻击账号库。  
降影响：柔性踢出、高风险动作验证、快速找回、标签库。

## 7. 指标

盗号客诉、高准盗号量、登录打扰率、验证量、风险 token 踢出、小号发生/漏过、黑市账号报价、注册合规率。
