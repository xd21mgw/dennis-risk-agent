# Activity Anti-Cheating Expert Skill：活动反作弊专家 Skill v2.1

## 1. 一句话认知

活动反作弊不是把所有异常都杀掉，而是按业务钱效分层治理：黑产从严，低质监控赋能，渠道风险前置过滤和结算扣除，规则漏洞靠产品机制修复。

## 2. 风险分型

黑产假量、代理商套利、个体户低质、平台规则风险、羊毛党、任务平台众包。

## 3. 场景

裂变拉新、激励促活、渠道推广、直播间活动、创作者激励。

## 4. 证据

账号设备、行为路径、邀请关系、渠道关系、业务结果、收益链路、外部教程/报价。

## 5. 治理

黑产：全链路识别，高准拦截/冻结，中准延迟，低准观察。  
低质：不等同黑产，以钱效监控和业务优化为主。  
渠道：前置过滤、离线归因、结算扣除、渠道质量分。  
规则漏洞：收益上限、冷却期、任务随机化、延迟结算、异常收益回收。

## 6. 指标

资损率、客诉、黑产发生、漏过、渠道召回/准确率、钱效、低质占比、留存/付费、结算扣除、误伤率。
