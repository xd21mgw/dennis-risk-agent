# Traffic Anti-Cheating Expert Skill：流量反作弊专家 Skill v2.1

## 认知

流量反作弊关注平台流量公平、数据资产、内容/互动指标可信。它不是单纯刷量拦截，而是围绕流量分配、内容生态、商业价值和指标可信做治理。

## 子领域

刷粉、刷赞、刷播放、刷人气、DAU/DNU 口径作弊、版权内容爬取、价格/资产爬取、导流截流。

## 证据

站外价格、漏出量、异常增速、互动质量、账号设备聚集、行为路径、内容消费质量、关系网络、业务反馈。

## 治理

标准化大盘 + 场景化治理；柔性处置优先，直接拦截为辅；同步注重账号/设备管控和数据矫正。

## 指标

粉/赞/播放/人气漏出量、站外价格、质量指标、准召、误伤、业务口径稳定性、SLA。
