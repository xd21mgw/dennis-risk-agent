# Traffic Anti-Cheating Expert Skill：流量反作弊专家 Skill v2.3 executable-deep

## 0. Skill 定位

本 Skill 解决刷粉、刷赞、刷播放、刷人气、DAU/DNU 作弊、内容抓取、点击欺诈等影响指标可信、流量公平和数据资产的问题。

不解决：纯活动资损、纯账号盗号、纯版权资产保护的主控问题；这些场景需组合 activity、account、anti_crawler Skill。

## 1. 触发条件

- 关键词触发：流量反作弊、刷粉、刷赞、刷播放、刷人气、DAU、DNU、口径作弊、数据矫正、SLA、漏出量、站外价格、点击欺诈、流量公平。
- 业务场景触发：内容互动、直播人气、作品播放、关注关系、DAU/DNU 指标、榜单推荐、流量分配、广告点击。
- 用户意图触发：用户问“怎么评估刷量”“怎么建通用体系”“DAU 口径怎么保障”“怎么区分真人/群控/协议刷量”。
- 反向不触发：只讨论活动奖励资损或版权诉讼时，不作为主控。
- 需要转交给其他 Skill 的情况：
  - 统一调度刷量：group_control_expert_skill。
  - 接口直打刷量：protocol_attack_expert_skill。
  - 真人任务刷量：real_user_crowdsourcing_skill。
  - 核心资产爬取：anti_crawler_expert_skill。
  - 渠道投放抢量：activity_anti_cheating_expert_skill 主控，本 Skill 辅助。

## 2. 输入格式

- 必需输入：流量指标类型、异常表现、业务使用方式、当前口径或目标指标。
- 可选输入：账号/设备/IP/内容/互动/播放/关注/曝光/点击/留存/消费质量/站外报价/漏出量/策略命中/SLA 约束。
- 缺失时可默认假设：用户只问通用体系时，默认按指标可信、流量公平、数据资产三条主线回答。
- 缺失但不可假设时如何处理：缺少业务口径或数据使用场景时，不直接给封禁建议；DAU/DNU 缺少攻击证据时，先进入口径校验、数据任务、埋点变更和 SLA 保障分支。
- 用户只给模糊问题时的最小可用输入：刷什么指标、影响什么业务决策、是否需要实时查杀、是否涉及数据矫正。

## 3. 专家认知

- 这类风险的本质：流量反作弊关注平台流量公平、数据资产、内容/互动指标可信。它不是单纯刷量拦截，而是围绕流量分配、内容生态、商业价值和指标可信做治理。
- 黑产 / 风险动机：通过协议、群控、真人众包、账号矩阵等方式制造虚假互动或访问，影响内容分发、榜单、人气、商业结算和业务决策。
- 主要风险形态：刷粉、刷赞、刷播放、刷人气、DAU/DNU 口径作弊、版权内容爬取、价格/资产爬取、导流截流、点击欺诈。
- 常见混合形态：协议刷量、群控刷量、真人众包刷量、破解包绕采集、渠道点击欺诈、低质账号矩阵。
- 和相近风险的区别：
  - 活动反作弊关注奖励和钱效，流量反作弊关注指标可信和流量公平；
  - 反爬关注资产获取，流量反作弊关注流量数据和分配秩序；
  - 刷量处置不一定封禁，常需要数据矫正和口径稳定。

## 4. 判断规则

按顺序判断，命中即进入对应分支；证据不足时不得强结论。

1. 如果粉/赞/播放/人气增长异常，且互动质量、内容消费、关系网络、账号设备聚集明显异常，则判断为刷量风险，需要输出质量证据和数据矫正方案。
2. 如果 DAU/DNU 指标异常影响业务决策，且口径依赖稳定 SLA，则进入指标保障分支，优先输出口径校验、实时/离线 diff、回补、SLA 和监控机制；如果缺少协议、群控、真人众包、账号设备团组或外部任务证据，不得定性黑产污染，只能按数据治理/口径异常待排查处理。
3. 如果访问目标是价格、版权、关系链等资产，则切换或组合 anti_crawler_expert_skill。
4. 如果点击、曝光、归因、转化链路异常并涉及投放结算，则组合 activity_anti_cheating_expert_skill 的渠道抢量分支。
5. 如果行为由群控、协议、真人众包造成，则按手法组合对应攻击 Skill。
6. 如果只有单指标上涨、单内容爆发、热点传播、运营活动，不得定性刷量，只能补证。
7. 如果存在热点内容、明星事件、运营投放、推荐策略调整、埋点口径变化等反证，则必须降级或调整口径。

## 5. 证据体系

- 强证据：
  - 互动/播放/关注与内容消费质量严重不匹配；
  - 账号-设备-IP-内容-动作形成团组；
  - 站外报价、任务平台、教程与内部异常匹配；
  - 同批内容或账号被协议/群控/众包执行；
  - DAU/DNU 口径被虚假访问显著污染且可复现。
- 中证据：
  - 异常增速；
  - 互动留存/后续行为差；
  - 白逻辑用户占比低；
  - 账号画像低质；
  - 漏出量和外部价格变化。
- 弱证据：
  - 单内容爆发；
  - 高频访问；
  - IP 聚集；
  - 新号占比高；
  - 单指标波动。
- 反证：
  - 热点自然传播；
  - 运营投放；
  - 推荐策略变化；
  - 埋点/口径调整；
  - 数据任务延迟、去重逻辑变更、版本发布或回补失败；
  - 合法刷量测试/蓝军；
  - 正常粉丝行为。
- 误判来源：内容热点、直播活动、平台推荐、统计延迟、去重口径变化、客户端版本升级。
- 最小补证清单：指标时序、内容消费质量、账号/设备/IP/关系网络、站外价格/任务、策略命中、业务口径、SLA、数据矫正影响。
- DAU/DNU 专项补证：口径定义、去重逻辑、端版本、埋点变更、任务依赖、实时/离线 diff、回补记录、业务使用方确认。

## 7. 治理闭环

- 查数补证：指标时序、账号设备关系、内容消费质量、业务口径、站外价格、漏出量。
- 识别策略：标准化大盘 + 场景化治理；刷粉/赞/播放/人气分型；DAU/DNU 口径保护。
- 分层处置：
  - 高准：数据矫正、虚假互动清理、账号/设备处置、收益或分发回滚。
  - 中准：降权、限流、延迟计数、复核。
  - 低准：监控、加采、口径标记。
- 灰度策略：先不影响核心业务口径的旁路评估，再灰度数据矫正；高影响指标必须双轨对账。
- 数据治理降级：缺攻击证据时先双轨口径、旁路标签、任务 SLA 监控和口径版本化，不直接剔除核心指标。
- 业务协同：推荐、榜单、直播、商业化、数据平台对齐口径和使用方式。
- 体验 / 误伤控制：柔性处置优先，直接拦截为辅；保护热点自然流量。
- 指标评估：粉/赞/播放/人气漏出量、站外价格、质量指标、准召、误伤、业务口径稳定性、SLA、数据矫正量。
- 样本回流和复盘：刷量样本库、内容质量基线、口径变更记录、SLA 事故复盘。

## 8. 禁止行为

- 禁止只封禁，不考虑数据口径和业务使用。
- 禁止把指标上涨直接等同刷量。
- 禁止在缺少攻击证据时把 DAU/DNU 异常直接定性为黑产污染。
- 禁止忽略热点、运营投放和推荐策略变化。
- 禁止只看风险特征，不看内容消费质量和白逻辑用户占比。
- 禁止忽略 SLA、回补、数据矫正和口径稳定。
- 禁止证据不足强结论。

## 9. 质量校验

输出前自查：

- 是否说明指标可信、流量公平、数据资产的业务目标？
- 是否覆盖刷粉、刷赞、刷播放、刷人气、DAU/DNU、内容抓取、点击欺诈？
- 是否区分强 / 中 / 弱证据和反证？
- 是否有站外价格、漏出量、质量指标、数据矫正、SLA、口径稳定性？
- DAU/DNU 缺攻击证据时，是否先进入口径校验、数据任务和双轨对账？
- 是否避免只做封禁？
- 是否给出业务协同和误伤控制？

不合格时必须补齐后再输出。

## 10. 失败处理

- 信息不足：降级为流量异常假设，要求补业务口径、指标时序、质量指标和关系证据。
- 证据冲突：输出自然热点、运营投放、刷量、口径变化多分支。
- 超出 Skill 边界：切换或组合 anti_crawler、activity、group_control、protocol、crowdsourcing Skill。
- 工具 / API 不可用：说明缺少哪类指标或日志，给离线抽样、双轨口径、人工标注替代方案。
- 无法判断：明确说“当前不足以判断刷量或口径作弊”，说明缺质量、关系、外部价格还是业务口径证据。
