# Anti-Crawler Expert Skill：反爬专项专家 Skill v2.1

## 1. 一句话认知

反爬不是单纯挡接口，而是围绕核心资产保护，让黑产获取资产的成本高于收益，并让平台可发现、可评估、可治理、可复盘。

## 2. 资产分级

| 资产 | 风险 | 治理态度 |
|---|---|---|
| 价格/库存/商品 | 跟价、倒卖、情报 | 高价值重点防控 |
| 版权内容 | 投诉、诉讼、盗版 | 防控+溯源 |
| 关系链/用户信息 | 导流、骚扰、定向添加 | 脱敏+权限+风控 |
| 流量数据 | 刷量、商业情报 | 监控+通用防护 |
| 低价值页面 | 普通访问 | 可发现可监控 |

## 3. 攻击路径

单纯协议、养设备协议、群控真机、破解包、真人众包、合作方/内部泄漏、前端/缓存泄漏。

## 4. 非常 6+1 反爬飞轮

1. 未接漏洞：敏感接口、弱端、无登录态；
2. 产品改造：权限、脱敏、展示、访问门槛；
3. 实时发现：分钟级异常、外部情报、报价；
4. 策略对抗：协议、群控、破解包、真人；
5. 风险处置：账号、设备、IP、资产；
6. 水位评估：TOP 请求账号量、报价、投诉；
+ 1 引擎：实时、准实时、离线、应急。

## 5. 证据

资产证据、技术证据、行为证据、关系证据、外部情报、结果证据。

## 6. 查数动作

确认资产 → 定位入口 → 前后端 join → 设备/账号/IP 聚集 → 接口序列 → 访问后业务行为 → 外部报价/投诉 → 蓝军/蜜罐验证。

## 7. 治理

资产最小化、展示脱敏、签名、token/设备绑定、端侧上下文、协议识别、群控识别、产品改造、弱端收敛、法务/诉讼支撑、评估回流。

## 8. 指标

黑市报价、TOP10w 请求所需账号量、版权投诉、取证召回/准确率、漏出量、业务误伤、黑产迁移。
