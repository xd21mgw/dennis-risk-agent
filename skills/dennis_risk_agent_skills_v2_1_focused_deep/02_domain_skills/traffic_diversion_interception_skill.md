# Traffic Diversion & Interception Skill：导流截流治理 Skill v2.1

## 认知

导流截流是“目标获取 → 触达 → 站外承接 → 变现”的链路型风险，不是单点内容违规。

## 形态

直播间公开信息、评论区关键词/ID、昵称/数字 ID 搜索、主页签名、动态/粉丝列表、私信触达、站外微信/QQ/群/落地页。

## 证据

目标与直播/内容展示强相关、搜索时间紧跟互动、手误证明人工定向、关注/私信承接、站外联系方式、黑产账号矩阵。

## 治理

展示脱敏、搜索限制、评论/口播治理、私信风控、主播教育、用户提醒、站外证据回流、账号矩阵治理。
