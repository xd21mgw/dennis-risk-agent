## 2023-2025 跨年度主线沉淀

### 增长 / 活动反作弊

稳定演进：

```text
应急止损 → 场景拉通 → 模式体系化 → 业务协同和站外投放
```

关键表达：

- 从“活动资损止损”升级到“增长钱效保障”；
- 站内：黑产对抗守基本盘，真人低质做厚价值；
- 站外：渠道投放反作弊从 0 到 1，进入归因评估、CPA 调价、结算扣除；
- 发现体系：内部监控、业务监控、外部情报、攻防演练交叉覆盖；
- 策略体系：大问题小解、小问题根解，从打地鼠变成通用策略包；
- 评估落地：内外双策略评估、自然量准确率、付费量误伤、归因沙盒、节省金额。

### 流量反爬 / 版权保护

稳定演进：

```text
接口式被动防控 → 核心资产分级 → 非常6+1体系 → 版权诉讼和资产保护价值
```

关键表达：

- 反爬目标是资产安全，不是只挡 API；
- 敌人模式包括竞对、黑灰产、三方公司、内部/合作开放平台；
- 漏洞类型包括未接反爬、未开签名、接口轰炸、白名单、接口复用、过度数据、越权、路径穿越；
- 高价值资产重投入重运营，低价值有监控重平稳，潜在可爬可监控推接入；
- 版权保护按前链路产品改造、中链路策略对抗、后链路取证诉讼组织；
- 价值指标用 TOP 请求关联账号量、黑市报价、投诉、取证召回/准确率、蓝军赛道表达。

### 账号安全

稳定演进：

```text
登录拦截 → 可信体系 → 历史负债清偿 → 账号生命周期治理
```

关键表达：

- 账号安全长期负债包括漏洞、不支持验证、token 永久有效、无法踢出登录态、弱端未接风控、核心指纹缺失；
- 治理主线是降负债、降发生、降影响；
- 可信层降低正常号主打扰，风险层识别盗号，兜底层建设验证体系；
- 盗号分型要区分信息泄露、欺诈盗号、token 泄露，以及协议/群控登录；
- 黑产账号要从注册扩到活跃、回扫、交易、下游作恶。

### 设备 / 黑灰产基建

稳定演进：

```text
点状采集 → 同步上报 → 风险取证 → 设备处置 → 跨场景基建
```

关键表达：

- 设备采集要从异步 SDK 升级到同步上报，借助网络库拦截器在核心接口上报；
- 风险 APP 取证用于还原敌人模式，反哺活动、爬虫、注册等场景；
- 设备处置从账号处置扩展到无感验证、强制登录、滑块验证、强制升级；
- 协议和群控基建是跨活动、反爬、账号的通能能力。

## 材料级表达原则

- 讲主线，不堆项目；
- 讲本质，不堆特征；
- 讲指标，但指标服务于判断；
- 讲短板，短板要能导向下一步；
- 学结构和认知，不机械复用历史年份和固定指标。

学习结构和判断方式，不照搬年份、指标和固定分支。
