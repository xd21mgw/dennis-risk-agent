# Query Intent To Data Source Map v1

## 0. 使用边界

本文件定义 `query_intent_type` 到抽象数据源的映射，不包含真实表名、字段名、SQL 或 API。

## 1. protocol_frontend_backend_join

- 适用问题：判断是否协议攻击；判断是否前后端链路不一致；判断是否破解包 / 埋点缺失造成前端缺失
- 需要的数据域：前端行为域、后端数据域、设备信息域、策略引擎域
- 最小输入：user_id 或 device_id；api_name 或业务动作；time_window
- 推荐维度：前端事件、后端请求、SDK 状态、接口序列、token/device/ip/ua、网关决策
- 期望输出：前端事件是否存在、后端请求是否存在、SDK 日志是否存在、接口序列是否异常、token / device / ip / ua 是否冲突
- 证据不足时降级规则：只有前端缺失时，不得直接判协议；降级为链路冲突待补证
- 不能直接下结论的情况：埋点缺失、破解包、官方版本问题、合法工具调用未排除

## 2. sdk_bypass_or_cracked_app_check

- 适用问题：判断 SDK 缺失、破解包、端侧采集绕过、协议误判排除
- 需要的数据域：设备信息域、前端行为域、后端数据域
- 最小输入：device_id 或账号集合、风险请求集合、time_window、版本/签名语义
- 推荐维度：SDK 状态、实时指纹、设备画像、app_version、app_signature、后端请求
- 期望输出：SDK 是否缺失、实时指纹是否异常、设备画像是否异常、app_version / app_signature 是否异常、是否存在前端采集缺失但后端请求存在
- 证据不足时降级规则：只有 SDK 缺失时，降级为端采集异常待排查
- 不能直接下结论的情况：官方版本缺失、埋点问题、采集延迟未排除

## 3. group_control_dispatch_check

- 适用问题：判断群控统一调度、活动黑产团组、反爬真机群控、直播间批量行为
- 需要的数据域：设备信息域、前端行为域、活动信息域、关联网络域、风险画像域
- 最小输入：账号/设备集合、业务动作、time_window
- 推荐维度：设备团组、行为路径、同批启动/停止、任务目标、收益/活动结果、合法矩阵
- 期望输出：设备团组、行为路径相似、同批启动 / 停止、任务目标一致、活动收益 / 结果聚集、合法矩阵反证
- 证据不足时降级规则：只有设备聚集时，降级为设备聚集异常
- 不能直接下结论的情况：企业网络、活动自然高峰、合法矩阵、测试流量未排除

## 4. token_reuse_or_account_takeover_check

- 适用问题：token 泄露、登录态复用、账号接管、盗号后敏感动作
- 需要的数据域：用户信息域、设备信息域、后端数据域、风险画像域、策略引擎域
- 最小输入：user_id/account_id/token_id、time_window、敏感动作语义
- 推荐维度：登录环境、token 使用环境、设备/IP/UA、换绑/找回/改密、策略命中、下游行为
- 期望输出：token 与设备 / IP / UA 是否冲突、登录环境是否突变、是否发生换绑 / 找回 / 改密、下游行为是否突变、是否已有盗号风险画像或策略命中
- 证据不足时降级规则：只有异地或 UA 变化时，降级为登录态异常监控
- 不能直接下结论的情况：正常换机、漫游、企业网络、多设备登录、SDK 升级未排除

## 5. activity_black_industry_or_low_quality_check

- 适用问题：活动黑产、活动低质、羊毛党、真人众包、邀请作弊、回流套利
- 需要的数据域：活动信息域、用户信息域、设备信息域、风险画像域、关联网络域、策略引擎域
- 最小输入：campaign_id 或活动语义、用户/账号集合、time_window、奖励动作语义
- 推荐维度：活动参与路径、邀请关系、回流状态、奖励/提现、后验质量、设备/用户团组、风险画像、策略命中
- 期望输出：活动参与路径、邀请关系、回流状态、奖励 / 提现状态、留存 / 付费 / 后验质量、设备 / 用户团组、风险画像和策略命中
- 证据不足时降级规则：只有低钱效或奖励多时，降级为活动低质/钱效治理
- 不能直接下结论的情况：活动机制、自然传播、冷启动目标、合法运营未排除

## 6. channel_attribution_hijacking_check

- 适用问题：渠道抢量、点击注入、点击洪泛、归因劫持、老客冒充新客
- 需要的数据域：渠道信息域、用户信息域、设备信息域、活动信息域
- 最小输入：channel_id/media_source/campaign_id、time_window、归因口径
- 推荐维度：曝光、点击、激活、CTIT、自然量/渠道量、新客真实性、老设备/老账号、后验质量、投放策略变化
- 期望输出：曝光 → 点击 → 激活链路、CTIT 分布、自然量 / 渠道量变化、新客真实性、老设备 / 老账号占比、后验质量、投放策略变化反证
- 证据不足时降级规则：只有 CTIT 异常时，降级为渠道归因异常待复核
- 不能直接下结论的情况：预算、活动、版本、归因规则、媒体策略变化未排除

## 7. anti_crawler_asset_leakage_check

- 适用问题：反爬资产泄漏、价格/库存/内容资产外流、外网跟价、关系链获取
- 需要的数据域：前端行为域、后端数据域、设备信息域、关联网络域、风险画像域
- 最小输入：资产类型、访问入口、对象集合、time_window
- 推荐维度：资产访问路径、接口访问量、前后端链路、设备/账号/IP 聚集、强目标访问、外部泄漏时间
- 期望输出：资产访问路径、接口访问量、前后端链路、设备 / 账号 / IP 聚集、是否存在强目标访问、外部泄漏与内部访问时间是否可对齐
- 证据不足时降级规则：只有外网样本时，降级为资产泄漏多路径排查
- 不能直接下结论的情况：缓存、前端公开信息、合作方、内部导出、真人访问未排除

## 8. traffic_diversion_chain_check

- 适用问题：直播间截流、站外添加、私信导流、主页/签名/动态承接
- 需要的数据域：前端行为域、用户信息域、关联网络域、风险画像域、后端数据域
- 最小输入：场景语义、目标用户集合、触达账号集合、time_window
- 推荐维度：信息暴露入口、搜索/关注/私信触达、主页/签名/动态承接、账号矩阵、投诉/举报
- 期望输出：信息暴露入口、搜索 / 关注 / 私信触达、主页 / 签名 / 动态承接、黑产账号矩阵、投诉 / 举报
- 证据不足时降级规则：无站外承接时，降级为导流嫌疑或触达异常
- 不能直接下结论的情况：正常社交、普通关注、用户主动外联、授权运营触达未排除

## 9. legal_operation_matrix_check

- 适用问题：合法矩阵、商家/MCN/达人批量运营、授权工具、局部超范围违规
- 需要的数据域：用户信息域、后端数据域、策略引擎域、关联网络域、风险画像域
- 最小输入：主体或账号集合、工具来源语义、time_window、操作场景
- 推荐维度：授权主体、账号范围、工具来源、操作人、调用接口、敏感动作、收益主体、历史违规
- 期望输出：授权主体、账号范围、工具来源、操作人、调用接口、敏感动作、收益主体、历史违规
- 证据不足时降级规则：缺授权信息时，进入审计补证
- 不能直接下结论的情况：只有批量行为，不能直接判群控/协议；有授权也不能放过导流、欺诈、支付风险

## 10. strategy_effect_and_false_positive_review

- 适用问题：策略效果评估、误伤复盘、灰度验证、查杀分离、策略回滚判断
- 需要的数据域：策略引擎域、用户信息域、前端行为域、后端数据域、活动信息域、风险画像域
- 最小输入：策略语义、命中对象集合、处置窗口、后验窗口
- 推荐维度：策略命中、处置结果、后验风险结果、业务指标影响、误伤样本、申诉/客诉、对照组
- 期望输出：策略命中量、处置结果、后验风险结果、业务指标影响、误伤样本、申诉 / 客诉
- 证据不足时降级规则：只有策略命中量时，不能判断策略有效或风险真实
- 不能直接下结论的情况：后验、对照组、申诉/客诉、业务影响未补齐
