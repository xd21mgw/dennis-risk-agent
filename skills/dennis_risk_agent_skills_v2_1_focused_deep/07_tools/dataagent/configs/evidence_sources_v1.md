# Evidence Sources v1

## 0. 使用边界

本文件定义风险证据需要哪些数据域支持。当前 Codex 阶段不调用真实 Data Agent，不编造真实表名、字段名、API 或真实结果。

## 1. 前后端链路一致性

- 证据名称：前后端链路一致性
- 适用风险：协议攻击、破解包绕 SDK / 绕采集、埋点缺失排查、反爬资产访问异常
- 需要的数据域：前端行为域、后端数据域、设备信息域、策略引擎域
- 最小输入：user_id 或 device_id、api_name 或业务动作、time_window
- 期望输出：是否存在服务端请求、是否存在对应前端事件、是否存在 SDK 日志、是否存在前后端链路冲突、是否存在策略命中或网关处置
- 强证据：关键请求缺少合理端链路，同时设备/SDK/网关/策略证据支持异常，且排除埋点缺失和口径问题
- 中证据：后端有请求、前端链路不完整，但 SDK/设备/口径证据未闭合
- 弱证据：只有前端无日志或单点请求异常
- 反证：破解包、埋点缺失、join 口径问题、日志延迟、官方版本问题、合法工具调用
- 不能直接下结论的情况：前端无日志不能直接判协议，需要排除破解包、埋点缺失、join 口径问题。

## 2. 协议攻击证据

- 证据名称：协议攻击证据
- 适用风险：单纯协议、养设备协议、token 复用协议、签名绕过协议、合法接口化调用误判排除
- 需要的数据域：前端行为域、后端数据域、NG 网关日志、风控实时指纹、风控引擎日志
- 最小输入：user_id/device_id/token_id、api_name 或业务动作、time_window
- 期望输出：是否无端请求、接口序列是否固化、token / device / ip / ua 是否冲突、网关是否识别异常、是否存在合法自动化反证
- 强证据：无端链路、接口直达、接口序列固化、环境冲突、网关/策略异常、合法自动化排除
- 中证据：接口序列异常或环境冲突明显，但端链路或授权排除不完整
- 弱证据：高频访问、接口量上涨、单接口异常
- 反证：合法自动化、官方工具、商家/达人/MCN 授权矩阵、埋点缺失、网关口径差异
- 不能直接下结论的情况：接口化调用不等于协议攻击；后端有请求但前端无日志不等于协议。

## 3. 破解包 / SDK 绕过证据

- 证据名称：破解包 / SDK 绕过证据
- 适用风险：破解包、SDK 缺失、端侧采集绕过、伪装正常端行为、协议误判排除
- 需要的数据域：风控异步 SDK、风控实时指纹、设备画像、前端行为、后端请求
- 最小输入：device_id 或账号集合、app_version/app_signature 语义、time_window、风险请求集合
- 期望输出：是否 SDK 缺失、是否实时指纹异常、是否设备画像异常、是否前端采集缺失但后端请求存在、是否存在版本 / 包 / 渠道异常线索
- 强证据：风险请求集中于异常版本/包/签名/SDK 状态，且能解释端侧采集缺失
- 中证据：SDK 缺失与风险请求相关，但缺工件级证据
- 弱证据：只有前端日志缺失或个别版本异常
- 反证：官方版本同样缺失、采集故障、埋点口径变化
- 不能直接下结论的情况：SDK 缺失不能直接判破解包，也可能是埋点、版本或采集问题。

## 4. 群控统一调度证据

- 证据名称：群控统一调度证据
- 适用风险：群控、活动黑产、反爬真机群控、导流矩阵、直播间批量行为
- 需要的数据域：设备画像、实时指纹、前端行为、活动信息、关联网络
- 最小输入：账号/设备集合、业务动作、time_window
- 期望输出：是否存在设备团组、是否同批启动 / 停止、是否行为路径高度一致、是否任务或目标一致、是否存在收益或活动结果聚集、是否存在合法矩阵反证
- 强证据：设备/账号团组、同批启停、路径模板、收益/目标聚集、合法矩阵排除
- 中证据：设备团组和路径相似明显，但收益或调度未闭合
- 弱证据：设备聚集、多账号、高频
- 反证：合法矩阵、企业网络、活动自然高峰、测试流量
- 不能直接下结论的情况：设备聚集不能直接判群控。必须看统一调度、行为路径、收益目标和反证排除。

## 5. 账号生命周期异常

- 证据名称：账号生命周期异常
- 适用风险：盗号、ATO、token 泄露、交易号、小号、二次放号、找回风险
- 需要的数据域：注册、登录、换绑、找回、改密、注销、风险画像
- 最小输入：user_id/account_id、time_window、敏感动作语义
- 期望输出：账号生命周期关键动作、登录环境变化、换绑 / 找回 / 改密异常、风险画像变化、下游行为突变
- 强证据：控制权变更链路与敏感动作、环境突变和风险画像变化闭合
- 中证据：生命周期动作异常明显，但下游风险未闭合
- 弱证据：账号新、注册短、单次异地登录
- 反证：正常换机、用户找回、客服处理、二次放号业务流程
- 不能直接下结论的情况：生命周期异常只是账号风险线索，需要设备、行为和策略引擎联合解释。

## 6. 活动黑产 / 低质证据

- 证据名称：活动黑产 / 低质证据
- 适用风险：活动黑产、羊毛党、真人低质、任务平台众包、回流套利、邀请作弊
- 需要的数据域：活动参与、邀请、用户回流、奖励 / 提现相关结果、设备画像、风险画像、用户团组
- 最小输入：campaign_id 或活动语义、用户/账号集合、time_window、奖励动作语义
- 期望输出：活动参与路径、邀请关系、回流状态、奖励领取 / 提现结果、留存 / 付费 / 后验质量、设备 / 账号 / 团组聚集
- 强证据：任务路径模板、设备/团组、奖励/提现聚集、收益链或任务平台线索闭合
- 中证据：奖励聚集、路径相似、后验质量差，但组织化证据不完整
- 弱证据：活动参与多、低钱效、低留存
- 反证：活动机制导致低质、自然传播、活动目标是曝光或冷启动
- 不能直接下结论的情况：活动低质不能直接等同黑产。

## 7. 渠道抢量 / 归因劫持证据

- 证据名称：渠道抢量 / 归因劫持证据
- 适用风险：点击注入、点击洪泛、归因窗口碰瓷、品牌量抢占、老用户冒充新客、子渠道倒量
- 需要的数据域：曝光、点击、激活、用户生命周期、设备画像、后验质量、活动回流
- 最小输入：channel_id/media_source/campaign_id、time_window、归因口径
- 期望输出：曝光 → 点击 → 激活链路、CTIT 分布、自然量 / 渠道量变化、新客真实性、老设备 / 老账号占比、后验质量、投放策略变化反证
- 强证据：CTIT 异常、自然量跷跷板、后验质量差、设备/IP/UA 或点击模板异常、业务变更排除
- 中证据：CTIT 和自然量结构异常，但点击/设备证据不完整
- 弱证据：渠道上涨、单点 CTIT 偏移
- 反证：预算、品牌活动、版本发布、归因规则变化、媒体策略变化
- 不能直接下结论的情况：CTIT 异常不能单独判渠道作弊。

## 8. 反爬资产泄漏证据

- 证据名称：反爬资产泄漏证据
- 适用风险：反爬、价格 / 库存 / 内容资产泄漏、版权内容外流、关系链 / 用户信息被获取、外网跟价
- 需要的数据域：前端行为、后端数据、NG 网关日志、设备画像、风控实时指纹、关联网络
- 最小输入：资产类型、访问入口、对象集合、time_window
- 期望输出：资产访问路径、接口访问量、前后端链路、设备 / 账号 / IP 聚集、外部泄漏时间与内部访问时间对齐
- 强证据：低成本批量访问、资产访问链路、异常设备/账号/IP 聚集、外部复用时间对齐
- 中证据：内部访问异常明显，但外部复用或入口未闭合
- 弱证据：外网跟价、单点截图、访问量上涨
- 反证：缓存、前端公开信息、合作方同步、内部导出、真人访问
- 不能直接下结论的情况：外网跟价不等于内部接口一定被爬。

## 9. 导流截流证据

- 证据名称：导流截流证据
- 适用风险：直播间截流、站外添加、私信导流、主页 / 签名 / 动态承接、黑产账号矩阵
- 需要的数据域：前端行为、用户关系、用户团组、私信 / 关注 / 搜索相关行为、风险画像
- 最小输入：直播间/场景语义、目标用户集合、触达账号集合、time_window
- 期望输出：信息暴露入口、搜索目标、关注 / 私信触达、站外承接线索、黑产账号矩阵、用户投诉 / 举报
- 强证据：信息暴露入口、目标获取、触达、站外承接、账号矩阵或收益链闭合
- 中证据：批量触达和目标获取明显，但站外承接不完整
- 弱证据：私信/关注异常、单账号偶发
- 反证：正常社交、普通关注、用户主动外联、授权运营触达
- 不能直接下结论的情况：私信 / 关注异常不一定是导流黑产。

## 10. 策略效果 / 误伤复盘证据

- 证据名称：策略效果 / 误伤复盘证据
- 适用风险：策略效果评估、误伤复盘、灰度验证、查杀分离、策略回滚判断
- 需要的数据域：风控引擎日志、策略命中、用户行为结果、客诉 / 申诉、业务 service 日志
- 最小输入：策略语义、命中对象集合、处置窗口、后验窗口
- 期望输出：策略命中量、处置结果、后验风险结果、用户申诉 / 客诉、业务指标影响、对照组差异
- 强证据：命中、处置、后验风险下降、误伤可控、对照组差异闭合
- 中证据：命中和处置有记录，但后验或申诉不完整
- 弱证据：只有策略命中量
- 反证：业务波动、实验流量、口径变化、申诉集中
- 不能直接下结论的情况：策略命中不等于风险真实发生，必须结合后验和人工复核。
