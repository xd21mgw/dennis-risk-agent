# Data Domains v1

## 0. 使用边界

本文件定义 Dennis 风控 Agent 常用数据域，用于指导 `query_intent` 选择“应该去哪类数据源查”。当前 Codex 阶段不访问真实数据，不编造真实表名、字段名或 API；真实映射由未来内部平台补充。

## 1. 用户信息域

- 数据域名称：用户信息域
- 包含的表族 / 日志族：注册、登录、换绑、找回、改密、注销
- 主要用途：判断账号身份、控制权、使用环境、生命周期是否发生变化
- 支持的风险问题：盗号、小号、交易号、token 异常、账号生命周期异常、二次放号、账号找回风险、账号被接管后行为突变
- 可支持的证据类型：注册时间、登录环境、登录设备、换绑行为、找回行为、改密行为、注销行为、账号生命周期变化
- 常见输入：user_id、account_id、时间窗口、账号动作类型、敏感动作线索
- 常见输出：账号生命周期摘要、登录环境变化、控制权变更链路、敏感动作前后关系
- 权限敏感等级：中高敏
- 注意事项：用户信息域常用于判断“账号是否发生身份、控制权、使用环境变化”，但不能单独证明黑产，需要结合设备、行为、风险画像和策略引擎。

## 2. 活动信息域

- 数据域名称：活动信息域
- 包含的表族 / 日志族：用户回流、邀请、参与活动
- 主要用途：分析活动参与、邀请关系、回流路径、任务完成和奖励结果
- 支持的风险问题：活动黑产、活动低质、裂变拉新作弊、回流套利、奖励异常、邀请关系异常、任务平台众包
- 可支持的证据类型：活动参与时间、邀请关系、回流路径、任务完成路径、奖励领取状态、活动后留存 / 后验质量
- 常见输入：campaign_id、活动语义、用户/账号集合、时间窗口、奖励动作语义
- 常见输出：参与路径、邀请图谱、任务窗口、奖励领取摘要、后验质量摘要
- 权限敏感等级：中敏
- 注意事项：活动参与和低钱效不能直接等同黑产，需要结合账号、设备、收益、留存、邀请关系和外部情报。

## 3. 渠道信息域

- 数据域名称：渠道信息域
- 包含的表族 / 日志族：曝光、点击、激活
- 主要用途：分析投放链路、归因、点击到激活时间差、渠道质量
- 支持的风险问题：渠道抢量、归因劫持、点击注入、点击洪泛、品牌量抢占、老客冒充新客、投放质量异常
- 可支持的证据类型：曝光时间、点击时间、激活时间、click-to-install / click-to-activate 时间差、渠道来源、归因类型、媒体来源、campaign 信息
- 常见输入：channel_id、media_source、campaign_id、时间窗口、归因口径
- 常见输出：曝光-点击-激活链路、CTIT 分布、渠道份额变化、新客质量、归因类型分布
- 权限敏感等级：中敏
- 注意事项：曝光、点击、激活受投放策略、预算、归因窗口、品牌活动影响。CTIT 异常不能单独证明渠道作弊。

## 4. 设备信息域

- 数据域名称：设备信息域
- 包含的表族 / 日志族：风控异步 SDK、风控实时指纹、设备画像
- 主要用途：识别设备环境、设备风险、设备与账号/token/IP/UA 的一致性
- 支持的风险问题：群控、协议、破解包、设备风险、渠道作弊、反爬、token 环境一致性、真机 / 模拟器 / 云手机 / 改机识别
- 可支持的证据类型：设备标识、实时指纹、异步 SDK 信号、设备画像、设备生命周期、设备环境相似度、设备与账号关系、设备与 token / ip / ua 的一致性
- 常见输入：device_id、user_id、token_id、IP/UA、时间窗口、客户端版本/签名语义
- 常见输出：设备画像摘要、实时指纹异常、SDK 覆盖摘要、设备团组、环境一致性
- 权限敏感等级：中敏
- 注意事项：设备聚集不能直接等同群控。设备画像可能存在更新延迟，实时指纹和异步 SDK 可能时效不同。

## 5. 前端行为域

- 数据域名称：前端行为域
- 包含的表族 / 日志族：PV / MV 日志、长链接日志、拉流日志
- 主要用途：还原页面路径、端侧事件、内容消费和行为节奏
- 支持的风险问题：协议排查、反爬、直播 / 内容风险、行为路径、前后端链路一致性、拉流 / 内容消费异常、群控行为节奏、真人众包行为质量
- 可支持的证据类型：页面路径、前端事件、曝光 / 点击 / 浏览、长链接状态、拉流行为、行为序列、停留时长、行为节奏
- 常见输入：user_id、device_id、页面/事件语义、直播间/内容语义、时间窗口
- 常见输出：页面路径、事件序列、拉流摘要、长链接状态、停留时长、行为节奏
- 权限敏感等级：中敏
- 注意事项：前端日志可能延迟、丢点、埋点缺失。前端无日志不能直接判协议。

## 6. 后端数据域

- 数据域名称：后端数据域
- 包含的表族 / 日志族：业务 service 日志、NG 网关日志
- 主要用途：还原服务端请求、接口链路、网关处置和风控传参
- 支持的风险问题：接口调用、协议攻击、服务端链路、网关拦截、请求序列、接口异常、反爬资产访问、风控传参和网关处置
- 可支持的证据类型：后端请求、接口名称、请求时间、请求来源、网关状态、风控参数、接口序列、服务端响应、拦截 / 放行 / 挑战结果
- 常见输入：api_name、业务动作、user_id/device_id、时间窗口、网关状态语义
- 常见输出：请求序列、服务端响应、网关决策、风控传参、接口异常摘要
- 权限敏感等级：中高敏
- 注意事项：后端日志需要与前端行为、设备信息、策略引擎日志联合解释。后端有请求但前端无日志，不等于一定是协议。

## 7. 风险画像域

- 数据域名称：风险画像域
- 包含的表族 / 日志族：小号、盗号、租借、其他风险画像标签
- 主要用途：风险分层、样本筛选、策略解释、处置分层和历史风险识别
- 支持的风险问题：账号安全、活动反作弊、反爬、导流截流、风险分层、历史风险识别
- 可支持的证据类型：风险标签、风险等级、历史风险类型、历史处罚、账号风险画像、设备风险画像、人群风险画像
- 常见输入：user_id、account_id、device_id、人群集合、风险类型语义、时间窗口
- 常见输出：风险标签摘要、风险等级、历史风险类型、处罚历史、画像分布
- 权限敏感等级：高敏
- 注意事项：风险画像可能是策略命中结果或模型推断，不等于事实标签。不能只因为有风险画像就下最终结论。

## 8. 策略引擎域

- 数据域名称：策略引擎域
- 包含的表族 / 日志族：风控引擎日志
- 主要用途：解释策略命中、风控决策、处置链路、灰度和效果评估
- 支持的风险问题：策略命中、风控决策解释、处置链路、误伤复盘、策略效果评估、灰度实验、命中链路诊断
- 可支持的证据类型：策略命中、风险分、决策结果、处置动作、灰度分组、引擎返回码、放行 / 拦截 / 验证 / 限权、命中规则链路
- 常见输入：user_id/device_id、策略语义、处置动作语义、时间窗口、灰度组语义
- 常见输出：命中摘要、决策链路、处置动作、灰度分组、规则链路
- 权限敏感等级：高敏
- 注意事项：策略引擎日志只能说明“策略命中 / 决策发生”，不等于风险真实发生。需要结合业务结果和人工复核。

## 9. 关联网络域

- 数据域名称：关联网络域
- 包含的表族 / 日志族：强设备关联、用户团组
- 主要用途：发现账号、设备、用户、收益、邀请、关注、私信之间的关联结构
- 支持的风险问题：群控、小号、黑产团伙、导流矩阵、关联扩散、收益聚集、账号交易、设备农场
- 可支持的证据类型：强设备关系、用户团组、账号共设备、设备共账号、账号关系网络、设备关系网络、邀请 / 关注 / 私信 / 收益关系
- 常见输入：user_id/account_id/device_id 集合、关系类型语义、时间窗口
- 常见输出：团组、关系边、关系强度、跨 case 复用、扩散候选
- 权限敏感等级：高敏
- 注意事项：团组和关联只能说明“存在关系”，不直接说明“存在作恶”。必须结合行为、收益、敏感动作和反证。
