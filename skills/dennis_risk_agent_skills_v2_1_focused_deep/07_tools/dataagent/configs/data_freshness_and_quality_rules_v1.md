# Data Freshness And Quality Rules v1

## 0. 目标

本文件定义 Data Agent 返回结果的质量风险，避免 Dennis 风控 Agent 误读数据。当前 Codex 阶段不调用真实 Data Agent。

## 1. 前端日志质量风险

- 可能延迟。
- 可能丢点。
- 可能埋点缺失。
- 可能版本差异。
- 前端无日志不能直接判协议。

解释要求：必须结合后端请求、设备 SDK、版本、渠道、采样和埋点口径。

## 2. 后端日志质量风险

- 可能和前端 join 口径不一致。
- 可能存在采样 / 延迟。
- 业务 service 和 NG 网关口径可能不同。
- 后端有请求不等于攻击成立。

解释要求：后端日志需要与前端行为、设备信息、策略引擎日志联合解释。

## 3. SDK / 指纹质量风险

- SDK 信号可能受版本影响。
- 破解包可能绕过 SDK。
- 实时指纹和异步 SDK 时效不同。
- SDK 缺失不能直接判破解包。

解释要求：SDK 异常必须结合包签名、版本/渠道、实时指纹、后端请求和官方版本对照。

## 4. 设备画像质量风险

- 可能存在更新延迟。
- 可能受设备重置 / 改机影响。
- 设备聚集不能直接判群控。

解释要求：设备画像只能作为设备风险线索，需要结合行为调度、收益目标和反证。

## 5. 关联网络质量风险

- 用户团组 / 强设备关联可能有离线延迟。
- 关联边不等于作恶边。
- 团组需要结合行为和收益解释。

解释要求：关联网络适合找团组和扩散候选，不应直接作为处罚依据。

## 6. 风险画像质量风险

- 风险画像可能来自策略命中或模型推断。
- 风险画像不等于事实标签。
- 不能只因风险画像下强结论。

解释要求：风险画像用于分层和先验，最终结论仍需行为、链路、收益或敏感动作证据。

## 7. 策略引擎质量风险

- 策略引擎日志说明命中 / 决策，不说明风险事实。
- 策略命中需要后验验证。
- 灰度和处置口径需要确认。

解释要求：策略引擎日志用于复盘和效果评估，不能替代风险事实证据。

## 8. 渠道数据质量风险

- 曝光 / 点击 / 激活 / 归因受投放策略影响。
- 受归因窗口影响。
- 受预算变化影响。
- 受品牌活动影响。
- CTIT 异常不能单独判渠道作弊。

解释要求：渠道风险必须结合自然量跷跷板、后验质量、设备/IP/UA 或点击模板，并排除预算、活动、版本和归因规则变化。

## 9. 活动数据质量风险

- 活动参与高不等于作弊。
- 低钱效不等于黑产。
- 回流用户质量需要结合活动目标解释。
- 邀请关系异常需要结合设备和收益链路。

解释要求：活动结论要区分活动低质、真人众包、群控和黑产套利。

## 10. 单日波动风险

- 单日 DAU / DNU 波动不能直接等同作弊。
- 需要趋势、对照组、渠道变化、实验变化、口径变化共同判断。

解释要求：单日指标异常先进入数据口径、SLA、实验、版本和活动排查，再判断风险。

## 11. 统一降级规则

- 数据返回 partial / failed / no_permission：必须降级为证据不足或待补证。
- 关键反证未排除：不得下明确判断。
- 只有单一数据域支持：最多高度疑似，通常需要补其他数据域。
- 只有风险画像或策略命中：不得直接定性风险真实发生。
- 样本量、窗口、join 口径不清：不得下强结论。
