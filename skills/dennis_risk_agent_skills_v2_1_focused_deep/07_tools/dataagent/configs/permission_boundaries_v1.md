# Permission Boundaries v1

## 0. 统一安全要求

- 当前 Codex 阶段不访问真实数据。
- 未来内部平台阶段必须做权限校验。
- 样本明细、敏感字段、批量导出、人群圈选必须有审批和审计。
- Dennis Agent 不自动处罚、不自动冻结、不自动扣除、不自动上线策略。
- 任何高风险治理动作必须人工确认。
- HRBI 不支持，遇到 HRBI 需求应说明不支持。

## 权限边界表

| 数据域 | 权限敏感等级 | 聚合分析 | 样本明细 | 是否需要审批 | 是否需要审计 | 是否可以导出 | 是否可以用于人群圈选 | 是否可自动触发治理动作 | 注意事项 |
|---|---|---|---|---|---|---|---|---|---|
| 用户信息域 | 中高敏 | 可，需最小化 | 受限 | 是 | 是 | 默认不可，审批后最小化 | 受限 | 否 | 涉及账号生命周期、登录、换绑、找回等敏感链路 |
| 活动信息域 | 中敏 | 可 | 受限 | 视场景 | 是 | 受限 | 可用于活动分层，需审批 | 否 | 奖励、提现、邀请关系需更高审计 |
| 渠道信息域 | 中敏 | 可 | 受限 | 视场景 | 是 | 受限 | 通常不直接圈人 | 否 | 涉及渠道结算时必须人工确认 |
| 设备信息域 | 中敏 | 可 | 受限 | 是 | 是 | 默认不可 | 可用于风险分层，需审批 | 否 | 设备指纹、SDK、画像均需最小化使用 |
| 前端行为域 | 中敏 | 可 | 受限 | 视场景 | 是 | 受限 | 可用于行为分层，需审批 | 否 | 页面路径和行为序列可能涉及用户行为隐私 |
| 后端数据 / NG 网关 | 中高敏 | 可 | 受限 | 是 | 是 | 默认不可 | 不建议直接圈人 | 否 | 接口、网关、风控传参敏感，需严格审计 |
| 风险画像域 | 高敏 | 可，需聚合 | 高度受限 | 是 | 是 | 默认不可 | 高度受限，需审批 | 否 | 画像是推断/策略结果，不能作为唯一处罚依据 |
| 策略引擎域 | 高敏 | 可，需授权 | 高度受限 | 是 | 是 | 默认不可 | 不直接圈人，需审批 | 否 | 规则、分数、决策链路高度敏感 |
| 关联网络域 | 高敏 | 可，需脱敏 | 高度受限 | 是 | 是 | 默认不可 | 高度受限，需审批 | 否 | 团组关系不等于作恶，禁止直接处罚化 |

## 高风险操作边界

以下动作必须人工确认：

- 冻结账号、封禁账号、扣除奖励、拒付渠道结算。
- 批量导出样本明细。
- 生成或导出人群包。
- 使用风险画像做强处置。
- 使用关联网络做团组级处罚。
- 上线强拦截策略或扩大灰度。

## Codex 阶段输出限制

当前只能输出：

- 数据域选择。
- 字段类型需求。
- query_intent。
- 权限风险提示。
- 质量风险提示。
- 人工补证清单。

当前不得输出：

- 真实数据结果。
- 真实 SQL。
- 真实表名/字段名。
- 内部 API。
- 自动处罚动作。
