# Batch Case Mock Regression Cases v1

## 0. 目标

本文件提供批量 case 共性分析的 mock 回归样例，用于测试 Dennis 风控 Agent 是否会过拟合、误判同源、误判黑产或过度统一治理。

当前阶段不调用真实 Data Agent，不编造真实表名、字段名、API 或真实结果。

## Case BATCH-001：协议疑似 case 同一埋点缺失

输入：多个 case 都表现为服务端有请求、前端无日志。

mock 共性返回：

- 同一官方版本、同一端 SDK 口径缺失。
- 接口序列不一致。
- token/device/ip/ua 无明显冲突。

期望解释：

- 批次结论：不同源同机制。
- 最大共性：版本/埋点口径。
- 不得判断协议团伙。
- 治理：修埋点、补 SDK 覆盖、重跑链路一致性。

## Case BATCH-002：群控真机同源同链路

输入：多个 case 都涉及真机设备访问核心资产。

mock 共性返回：

- 设备/账号团组跨 case 复用。
- 同批启停。
- 路径模板一致。
- 核心资产访问集中。
- 合法矩阵排除。

期望解释：

- 批次结论：同源同链路。
- 可明确判断群控真机批量获取资产。
- 治理：打团组 + 打入口 + 资产访问成本提升。

## Case BATCH-003：活动低质被误判黑产

输入：多个活动 case 后验质量低、奖励领取多。

mock 共性返回：

- 无设备团组。
- 无提现聚集。
- 无任务平台线索。
- 同一活动规则导致任务路径一致。

期望解释：

- 批次结论：不同源同机制。
- 当前最多为活动低质或规则问题。
- 不得定义活动黑产。
- 治理：优化活动门槛、奖励节奏、后验监控。

## Case BATCH-004：合法矩阵批量运营

输入：多个账号批量登录、批量发布、批量私信。

mock 共性返回：

- 授权主体、账号范围、工具来源和操作人审计存在。
- 部分私信动作超范围。
- 无系统性收益异常。

期望解释：

- 批次结论：同源不同链路或合法矩阵下局部违规。
- 不得一刀切判群控或协议。
- 治理：局部私信限权、敏感动作二次验证、审计回流。

## Case BATCH-005：直播间截流同一触达矩阵

输入：多个直播间用户被站外添加。

mock 共性返回：

- 信息暴露入口相同：评论/昵称搜索。
- 触达账号矩阵跨直播间复用。
- 私信内容模板相似。
- 站外承接证据部分闭合。
- 授权客服/达人运营未命中。

期望解释：

- 批次结论：高度疑似同源同链路。
- 不默认转反爬或协议。
- 治理：私信风控、搜索限制、入口脱敏、用户提醒、站外证据回流。

## Case BATCH-006：渠道 CTIT 异常由归因规则变化导致

输入：多个渠道 case CTIT 偏移、渠道份额变化。

mock 共性返回：

- 同一归因规则调整窗口。
- 后验质量无显著异常。
- 无设备/IP/UA 或点击模板异常。

期望解释：

- 批次结论：不同源同机制。
- 不得判断渠道抢量。
- 治理：口径校准、归因看板标注、结算复核而非扣减。

## Case BATCH-007：token 泄露同源资源复用

输入：多个账号敏感动作异常。

mock 共性返回：

- token 在新设备/IP/UA 上复用。
- 无登录迁移和验证链路。
- 敏感动作模板相似。
- 企业网络、漫游、正常换机反证排除。

期望解释：

- 批次结论：同源同链路。
- 可明确判断 token 泄露/登录态滥用。
- 治理：登录态刷新、step-up 验证、敏感动作冷却、样本回流。

## 回归评分规则

- 如果只因表象相似判断同源，最高 70。
- 如果没有反证，最高 80。
- 如果没有治理分群，最高 85。
- 如果把 Data Agent mock 结果当真实数据，最高 60。
- 如果 partial / failed / no_permission 未降级，最高 75。
- 如果能正确输出同源同链路、同源不同链路、不同源同机制、表象相似和证据不足，且治理动作分层，90+。
